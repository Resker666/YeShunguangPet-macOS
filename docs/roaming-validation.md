# 小范围走动验证

开发与验证日期：2026-10-20–21（Asia/Shanghai），版本0.1.8（build 9），Mac mini M4 / macOS 27.0 / Xcode 27.0。

用户批准本会话实施小范围走动，复用独立Mac仓库，在codex/macos-desktop-roaming分支开发，不另建工作树。只做本地交付，不推送或发布。

## 实现范围

默认关闭，独立保存开关与20–180秒间隔，默认75秒、每次±25%浮动。使用皮肤原有左右循环行走动画；缺失时不触发，偏好保留。每次60–120逻辑点、40点/秒，空间不够时缩短距离，在当前屏幕visibleFrame内选择能走的方向，到目标停止，不跨屏。至少需一侧有24点空间；角色放不下或没有可用屏幕时不走动。

沿用Windows只读提交242aab0的矩形距离与迟到限速设计，针对本轮低打扰目标缩短距离并降低速度。约33ms更新位置，单次迟到最多按0.1秒计算，避免瞬移；鼠标距角色矩形≤80点时暂停，离开100点后恢复，近鼠标暂停时100ms检查。到触发时间仍有鼠标接近则500ms重查，不积压动作。没有后台全局输入监听，不记录鼠标坐标。

点击/拖动、菜单/设置、手动动作、隐藏、睡眠、屏幕变化和换肤会结束本次走动，回待机再等待。走动与自动小动作互斥，优先级参考原版：都到期时先走动；注视可以在待机时响应，走动与近鼠标暂停中不替换走动状态。所有期限合并到现有单一FrameScheduler，无额外常驻定时器。走动结束或中断有位移时才保存，位移期间不逐帧写盘。保存前重新限制窗口到有效显示区域，失败提示沿用现有重试流程。

配置schema6读取1–5，迁移时走动关闭/间隔75，其余偏好、导入UUID和位置保留。v6字段缺失、类型错误、超范围保留原文件。开关关闭、不支持的皮肤不额外读鼠标或枚举屏幕。

## 原生回归

基线114项通过。新策略8项空实现出现12处预期失败后通过；夹具首次两处Swift运算符空格错误只算编译失败，不计行为RED。配置迁移出现6处失败、PetSession接线出现21处失败，再实现对应行为。

首次完整回归发现屏幕变化中断时，保存位置已映射到新屏幕而窗口仍停在旧位置。现于走动保存前同步限制实际窗口；原失败回归通过。另补关闭/不支持时不得额外枚举屏幕，先观察2处失败，再在期限未到时提前返回，避免空闲开销。

最终完整135项（74 Core + 61 Mac）通过，日志.build/roaming-validation/native-final.log。覆盖方向/裁帧、短距离/负坐标/小屏、暂停与100点退出范围、迟到限速、窗口取整、单一定时器、只在结束写盘、位置重开恢复、手动互动/生命周期优先、与自动动作/注视协调、无屏中断/保存失败重试/重开、开关/间隔和配置迁移。

独立只读评审无Critical，发现1项Important：无可用屏幕时中断走动，两次capture返回nil，会写回走动前位置。现保留本次走动使用的屏幕快照和最新原点，无屏时也能更新待保存位置。回归先观察4处失败（no-screens-red.log），再修复并完成全套验证。评审另有1项Minor建议：补两种自动行为完全同到期时的直接优先级回归，已记待办；当前错峰互斥和实现顺序已有覆盖/检查。真实系统场景继续标未测，待生成包会在最终核验完成后记录；未把静态评审当作系统实测。

实际进程首轮在左边界起步，位移统计16.189点与保存原点24→0不一致，进程检查据此失败（real-processes.log）。查明每次用窗口取整后的原点继续积分会累积速度偏差；新增字面值回归观察102.32/104.32而非102.64/103.96的失败（pixel-rounding-red.log），改为由策略保留连续位置，并按设置窗口后的实际差值统计位移。重跑结果另记于后文。

最终退出补查进一步覆盖“屏幕已不可用，但无屏通知尚未到达便退出”。原路径仍可能保留旧点且动作未结束，先观察2处失败（quit-no-screens-red.log），再将requestExit调整为先结束走动、再执行正常保存；完整回归随后重跑。

## 交付核验

ARM与Intel Release构建及ad-hoc签名通过。初次完整分发10项通过（42.880秒）；旧App迁移测试先观察schema5而非6失败，再验证新版迁移、设置/选择和实际重开。评审及取整修复后的完整分发10项通过（54.491秒，退出0）；退出顺序补查后的最终完整分发10项通过（48.304秒，退出0），日志distribution-final.log。

三套原始皮肤经生产导入器复制，JSON/PNG字节和原始SHA-256保持一致。100%/150%/200%下分别验证左右行走、目标位移60/90点、结束回idle、期间不写盘且完成只保存一次，共核对16848个裁帧像素与原精灵图相同（real-skins.json/probe-run-final.log）。此为生产AppKit组件配合注入时钟和鼠标位置，不是用户真实鼠标体验。设置预览来自本App原生视图缓存绘制，已查看桌面走动开关、间隔、说明及底部区域无裁切；探针Bundle显示开发版，实际交付版本另外核对。

修复后，实际ARM App使用三套副本，开启20秒走动、关闭注视和自动小动作，各运行约30秒，均完成一次走动、回待机并保存位置。每套再启动独立进程，角色、缩放、开关、间隔、UUID和走动后位置均恢复正确；关闭组走动次数/位移/鼠标采样均为0。工作目录为/private/tmp，不依赖Xcode/DYLD环境；临时配置和Skins一起隔离，不移动用户鼠标（real-processes.json/real-processes-final.log）。

## 验证边界

原生注入时钟、鼠标位置、屏幕矩形及睡眠门控不等于真实鼠标、外接显示器或系统睡眠实测。焦点、Spaces、全屏、锁屏/睡眠、真实多屏和Intel／黑苹果仍待验证。本版本整体体验等待用户反馈；不扩大0.1.7已有验收范围。安装包仍为ad-hoc、未公证；本机搬移启动不等于外机或网上下载后的Gatekeeper首开通过。Windows与Minimal Sleep只读，真实JSON/PNG保留原字节。
