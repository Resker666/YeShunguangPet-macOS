## 分开保存的内容

## 恢复范围

备份内 `snapshot/` 保留原仓库相对结构。恢复时先校验，再复制到新的空目录，避免覆盖现有工作目录；权重和模型数据可按原布局恢复，不需要重新训练。

Python 虚拟环境与缓存未复制。重新建立兼容的 Python 3.12 环境需要安装依赖，并准备 FFmpeg；版本导出不是离线安装包。实验脚本及部分历史 JSON/YAML 含本机绝对路径，换目录后需按恢复目录调整，不能直接把备份当作可双击安装的语音包。未执行新环境重建或恢复后的推理，不把文件校验记作恢复运行通过。
