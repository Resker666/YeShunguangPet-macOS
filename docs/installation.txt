叶瞬光桌宠 · 免费体验版

适用范围
请先查看本说明顶部的安装包架构或下载文件名：
arm64：Apple Silicon（M 系列）Mac。
x86_64：Intel兼容测试版，真实Intel／黑苹果运行尚未验证。
两种包不能在另一种处理器上原生运行；M系列用户请选择arm64包。
从0.1.19起部署目标为 macOS 14.0；旧版安装包仍要求15.0。
目前只在 Mac mini M4 / macOS 27.0 实测，macOS 14尚待实机验证。
其他系统、真实Intel／黑苹果及未安装 Xcode 的另一台 Mac 尚待验证。
使用本软件不需要安装 Xcode、Swift、Python 或其他依赖。

安装
1. 打开 DMG（ZIP 请先解压）。
2. 把 YeShunguangPet.app 拖到旁边的 Applications／应用程序。
3. 弹出磁盘映像，再从“应用程序”打开叶瞬光桌宠。
4. 出现桌面角色后，使用菜单栏的爪印图标操作。

首次打开的系统提示
这是免费、未公证的体验包，使用本地 ad-hoc 签名。
从网上下载后，macOS 可能提示无法验证开发者或无法检查恶意软件。
请先确认下载来源和文件完整；若你信任本程序，在尝试打开后进入：
系统设置 → 隐私与安全性 → 仍要打开，然后按系统提示确认。
公司或学校管理的 Mac 可能限制此选项，需要遵循管理员策略。
DMG 包装不会消除安全提示。若提示文件损坏，请先重新下载并反馈，
不要把所有“已损坏”提示都当作普通的首次打开提示。
Apple 官方说明：https://support.apple.com/zh-cn/102445

使用与退出
拖动：移动角色，松开后保存位置。
单击：挥手；等待系统双击判定间隔后播放。
双击：跳跃。
菜单栏爪印：显示／隐藏角色、召回角色、设置、退出。
设置：角色大小50%–200%、保持置顶；立即生效，重开保留。
注视鼠标：默认开启，关闭设置窗口后，待机角色会短暂看向附近鼠标。
约2秒后恢复待机；离开范围再靠近可再次触发，可从设置关闭。
菜单、设置、点击与拖动期间暂停；无注视素材的皮肤继续待机。
换肤：设置 → 选择皮肤，选择一套皮肤的ZIP、皮肤文件夹或pet.json，
预览后点“导入并使用”；“恢复默认皮肤”切回随附角色。
清单与对应PNG按原字节保存副本，不改写原文件。ZIP可带外层文件夹，
但一次只识别一套皮肤；若含多套、加密、ZIP64或不支持的编码/压缩方式，
请先解压后选择其中一套。无效或过大的包会提示，当前角色保持不变。
设置的“已导入皮肤”列出已有副本，可点“使用”直接切换。
垃圾桶按钮确认后删除未使用的副本，不删除原始文件。
当前使用、配置仍记住或受保护配置下的皮肤不可删除。
正常退出会等待导入及本次撤销清理；强制结束或断电没有此保证。
关闭设置窗口不会退出桌宠；关闭置顶后角色可被其他窗口遮挡。
App 不显示 Dock 图标；关闭 DMG 不会退出已安装的 App。
若角色不见了，请从菜单栏选择“召回角色”。
本版不要求录屏、辅助功能或麦克风权限。只在手动检查更新时
查询公开GitHub版本信息，不自动下载更新或上传日志。

更新与卸载
更新前先从菜单栏退出，再用新版 App 替换“应用程序”中的旧版。
卸载前先退出，再把 App 移到废纸篓。
若曾开启登录时启动，请先在设置中关闭；也可在系统设置的登录项中移除。
位置、大小、置顶、注视、自动动作、走动和台词偏好保留在：
~/Library/Application Support/YeShunguangPet-macOS/settings.json
这允许重新安装后恢复位置与偏好；卸载 App 不会自动删除个人配置。
导入素材保存在上述目录同级的Skins文件夹；卸载App也会保留。
新版兼容schemaVersion 1–12配置，保存后升级到13；旧版App不能读取
新版配置，会保留原文件并提示，避免静默覆盖。

自动小动作（0.1.7）
默认关闭。在菜单栏 → 设置 → 自动小动作开启，间隔15–120秒，默认约60秒，带±25%浮动。关闭设置窗口后开始等待；点击、拖动、手动动作、菜单、设置、隐藏和睡眠期间暂停。关闭开关立即停止自动动作，偏好和间隔会保存。皮肤没有可用动作或显式空规则时不触发。

小范围走动（0.1.8）
默认关闭。在设置的“桌面走动”开启，间隔20–180秒，默认约75秒，带±25%浮动。关闭设置后开始等待，每次约60–120逻辑点，限制在当前屏幕可用区域内，走完保存位置。鼠标靠近暂停，离开后继续；点击、拖动、菜单、设置、隐藏和睡眠结束本次走动。皮肤需有左右循环行走动画，空间不足时不移动。

日用与互动（0.1.9）
菜单栏“安静模式”临时停止注视、自动动作、走动与台词，手动点击和拖动仍可用。取消后恢复原偏好，重开App恢复正常。
设置 → 互动台词 → 显示互动台词，默认关闭。单击确认及拖动结束时显示约6秒，至少间隔30秒；双击不显示。皮肤未提供文案时使用默认回应，显式空数组保持静默。
设置 → 启动 → 登录时启动，默认不替你开启。需先安装并从“应用程序”运行；状态由macOS管理。若提示需系统允许，可点“打开登录项设置”处理，真实重新登录效果请按需验证。
