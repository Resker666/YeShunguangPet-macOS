# 0.2.0 角色聊天里程碑

日期：2026-10-23。用户在确认聊天验收后表示“这个版本比较跨度大我认为可以是一个大版本了”；据此将本轮功能版本从本地开发号0.1.22提升为 **0.2.0 / build24**，突出角色聊天这条新主线。

本轮保留当前Applications中用户正在使用的0.1.22，不退出、不替换，不读取日用密钥或聊天记录。用户可在方便时安装0.2.0本地包。新的安装包与旧版功能相同，后续推送和发布等待明确指令。
