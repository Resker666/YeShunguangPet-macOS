# YeShunguangPet 0.7.0

这次公开版从0.1.19更新到0.7.0：桌宠现在可以文字聊天、记住你确认的内容，并使用系统中文语音或独立安装的本地角色音色。App、公共语音引擎和角色音色包分别下载，更新App通常不需要重下语音资源。

## 主要变化

- **DeepSeek角色聊天**：可编辑人设，流式回复，支持停止与复制；按角色保留最近12轮完整问答，重开续聊。API密钥保存在macOS钥匙串。
- **长期记忆**：点击后从最近对话提炼最多5条候选，编辑勾选并确认才保存；每角色最多20条，支持查看、修改和删除。
- **角色旁快速聊天**：与完整聊天窗共享会话和草稿。模型可以提议开始、暂停或继续专注，以及设置安静模式，显示明确操作卡，由你确认后执行。
- **系统中文语音**：主动录音转为可编辑草稿，再手动发送；支持中文朗读和打断。本机识别不可用时，可单次允许Apple在线识别。
- **M系列本地角色音色**：App内离线安装独立引擎、导入并按角色绑定音色；无需自行安装Python或Homebrew。生成和播放都可停止，空闲3分钟释放引擎。
- 补充使用帮助和手动复制诊断信息，修复此前发现的日期通知崩溃、语音音色查询卡住，以及本地语音引擎关闭输入管道时可能导致App退出的问题；原有换肤、桌面互动和专注计时继续保留。

## 下载与安装

最低系统要求 **macOS 14.0**。使用App无需安装Xcode。

| 设备 | 推荐安装包 |
| --- | --- |
| M系列Mac | `YeShunguangPet-0.7.0-macOS-arm64.dmg` |
| Intel Mac／黑苹果 | `YeShunguangPet-0.7.0-macOS-x86_64.dmg`（实验包） |

打开DMG，将App拖入Applications，弹出DMG后从“应用程序”打开。另提供同架构ZIP和SHA256文件。更新前先通过菜单栏退出旧App，再替换安装；原设置、皮肤、聊天、记忆及已有语音资源保留，建议先备份个人数据。不要同时运行新旧App。

这是ad-hoc签名、未公证的免费体验包。首次打开可能被系统拦截，先核实来源与摘要，再按[Apple官方说明](https://support.apple.com/zh-cn/102445)处理；DMG不会消除安全提示。

## 启用本地角色音色（可选，仅M系列）

前往[独立语音资源1.0.0](https://github.com/Resker666/YeShunguangPet-macOS/releases/tag/voice-assets-v1.0.0)下载引擎DMG（约2.05GB）和胡桃e1 ZIP（约161MB）。资源与普通App分开发行，首次只使用基础桌宠或文字聊天时无需下载。

1. 打开引擎DMG，在完整聊天的「语音 → 安装或修复本地引擎…」中选择卷内实际含`engine.json`与`payload`的引擎文件夹，预览后确认，等待自检完成。
2. 先解压音色ZIP，导入实际包含`voice.json`、`s2.pth`、`reference.wav`的「胡桃-试用-e1」三文件目录。App当前不直接导入音色ZIP。
3. 为当前角色应用绑定，主动启用语音后试听。安装与导入不会自动发声。

详细步骤、恢复方式及来源限制见资源页的中文安装说明。引擎展开约3.01GB，安装需要额外空间并保留旧引擎；首次启动和生成需要等待。

## 使用与验证范围

AI与语音默认关闭。文字聊天及记忆提炼会请求你配置的DeepSeek API，可能产生服务商费用；本地音色只负责语音生成，文字聊天仍联网。主动录音需要麦克风与语音识别权限，选择Apple在线识别时录音可能交给Apple处理；识别文字需检查后手动发送。

当前真实设备证据覆盖Mac mini M4。Intel版已交叉构建并核对安装包；旧0.1.19在一台Sonoma14.8.9黑苹果上的用户通过反馈，不能视为0.7.0已获Intel实机验证。macOS14、其他M系列、外机安装和Gatekeeper首开仍待验证。保留既有未测系统场景与已知限制，不宣称全部功能逐项通过。
