本地语音资源1.0.0（M系列预览），与普通App安装包分别管理。

需要YeShunguangPet **0.7.0/build30或后续兼容版**及M系列Mac。资源包括：

- 公共引擎1.0.0 DMG及SHA-256；已无损重压缩至约2.05GB，原28,828份payload文件及执行权限保持。
- 胡桃试用e1 ZIP及SHA-256；解压后保留原`voice.json`、`s2.pth`和`reference.wav`，来源说明位于三文件目录外。
- 小体积资源清单与中文安装说明。

使用方式：安装兼容App；打开引擎DMG；在完整聊天「语音 → 安装或修复本地引擎…」选择挂载卷内的实际引擎文件夹并确认。胡桃ZIP先解压，再导入三文件目录，为当前角色绑定并主动启用语音。安装完成后可弹出DMG，普通App更新无需重复安装同版资源。无需Xcode、Homebrew或外部Python。

当前只在M4验证包完整性与现有离线安装接口；macOS14、其他M系列、外机Gatekeeper仍待实际验证。Intel App可继续使用文字/系统语音，本ARM引擎不支持Intel。程序ad-hoc签名、未公证。

引擎内保留Python、106项依赖及公共模型的来源/许可；胡桃包附游戏原声来源。S1v3官方MIT声明对应的SHA已核对；ERes2NetV2 checkpoint专属声明、G2PW镜像与作者checkpoint内部对应关系、胡桃素材公开再分发依据仍未核实。这些内容不能统一称为本项目MIT资产；原声/权重与程序代码来源分别说明。胡桃e1是有限试音的实验结果，不保证任意文本或完整复刻质量。

本条为独立资源预发布，不替代普通App Latest。当前App0.7.0来自Actions产物，需登录下载且有14天保留限制；公开旧版0.1.19不支持本资源。普通App公开Release另行处理。原始训练录音、训练环境、个人设置和聊天资料不在附件内。
