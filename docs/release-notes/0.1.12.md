菜单和关于页现在可手动检查本项目的GitHub公开更新，显示当前版本与公开版本的关系、纯文本说明及对应架构安装包入口；默认启动不联网检查，不自动安装。下载和发布页按钮交给浏览器打开，查询失败可重试。

新增可配置全局快捷键，用于显示/隐藏角色、召回和切换安静模式。默认不绑定，在设置中选择至少两个修饰键（含Control或Option）和美式物理按键后应用；支持清除及冲突重试，登记或保存失败显示实际状态。菜单和模态确认期间暂停，按住不会连续切换。

设置按皮肤、通用、互动、快捷键、关于分为五组。任意页拖入皮肤仍先预览再确认，原素材保持不变。配置升级schema8，兼容1–7并保留旧偏好、皮肤与位置；旧版本App会保护不认识的新配置。
