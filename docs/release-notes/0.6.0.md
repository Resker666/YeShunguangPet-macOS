本地角色音色首版：在完整聊天的语音页导入可信文件夹语音包，预览确认后为当前角色应用绑定。默认不启用、不绑定、不发声；两种聊天窗共享一个输出，显示启动、生成、播放与实际音色，并可停止生成和播放。

当前 M4 的独立引擎按需加载，连续回复可复用，空闲 3 分钟释放。本地单次最多 600 个 UTF-16 单元，主动朗读更长回复会提示并用系统音色读全文；播放前失败且停止成功时最多回退一次，取消和播放后失败不重读。正常退出等待引擎、播放器和临时文件，失败可重试或取消退出。

M 系列 Mac 下载 arm64，Intel 下载 x86_64，最低 macOS 14。普通 App 无需 Xcode，包为 ad-hoc、未公证。本版独立本地引擎先覆盖当前 M4；Python、公共模型、角色权重和参考音频不随 App 附件分发，其他 Mac 的引擎安装与 Intel 引擎尚未验证。系统语音与文字聊天仍可独立使用。细节见仓库 docs/local-voice-usage.md 与验证记录。
