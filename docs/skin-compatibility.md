# 皮肤兼容矩阵

参考 Windows 提交：242aab04c6b6fc94e107eefa9fa216a4ee2e77e7，schemaVersion 1。

| 内容 | 读取/校验 | 当前执行能力 |
| --- | --- | --- |
| UTF-8 / BOM、字段大小写、未知与重复字段 | 支持；拒绝大小写不同及转义后的重复键 | 严格校验后加载 |
| ID、名称、描述、格尺寸、图像上限 | 按原规范限制；文本上限使用 UTF-16 单元 | 窗口尺寸来自单格 |
| PNG | 有界读取、普通文件、PNG 头/尺寸、实际解码、禁止资源链接与目录越界 | 原像素裁帧、透明绘制 |
| idle | 必需且循环 | 待机 |
| runningRight / runningLeft | 可选 | 拖动方向；缺失回 idle。两者均循环时可选小范围自动走动 |
| waving | 可选，单次 | 单击与召回；缺失回 idle |
| jumping | 可选，单次 | 双击；缺失回 waving，再缺失回 idle |
| failed / waiting / running / review | 识别及校验 | failed可由自动规则使用；其他暂无入口 |
| lookDirections | 省略、空数组或16个合法坐标；null拒绝 | 从上起顺时针16向注视，默认开启，近距短时响应；无帧则停止采样 |
| speech | 四类数组及文本限制；省略/null合法 | 可选执行click/drag/focusCompleted/breakCompleted。个人覆盖优先，其次皮肤及默认台词，显式空保持静默；完成事件须计时到期且角色允许回应 |
| behavior | 默认值、规则数量、条件、动作引用、时长、权重、冷却和重复条件 | 可选低频动作，默认关闭；条件/权重/独立冷却，省略或null回退可用挥手/跳跃，显式空表不触发 |
| 本地皮肤导入 | 选择文件夹或pet.json，按同一套严格规则校验 | 待机首帧预览、原字节副本、即时切换、重开恢复、默认回退 |
| 已导入皮肤库 | 识别既有UUID普通目录，逐项校验 | 名称/小缩略图/使用状态、无重复复制切换、确认删除非当前副本、正常退出等待本次清理 |
| 缩放 | 设置50%–200% | 保留原图像素，调整窗口逻辑点尺寸 |
| ZIP导入 | 0.1.10支持 | 一套皮肤、根目录/外层文件夹，Stored/Deflate及UTF-8/Unicode路径；其余限制见README，不改写原字节 |
| 个人台词 | 按清单ID存于App配置 | 四类整组覆盖、应用/确认清除，不会改写原皮肤JSON/PNG |
| 皮肤编辑 | 未实现 | 不会改写原皮肤 |
| Windows 个人配置、密钥、专注历史 | 不导入 | 独立 Mac 配置 |

App只随附叶瞬光PNG；知更鸟和胡桃可通过本地导入使用，未增加到分发包。首版加载证据见validation.md，本轮真实素材检查与交互边界见[皮肤导入记录](skin-import-validation.md)。
