# 胡桃本地角色音色接入设计

日期：2026-10-27（Asia/Shanghai）。基线 `cbe6ae4`，日用 App 为 0.5.1/build28。

状态：用户已要求开始接入，明确选择“先接通当前 M4，通用引擎安装包后续做”。本稿提出 0.6.0/build29 的具体行为与边界，尚待书面设计审核；不是已完成实现或安装验证。继续本会话原地开发、一次最终独立整体代码评审与本地 App 交付，不另建工作树。本版推送、标签与 Release 未获授权。

## 1. 目标及已有证据

在当前 Mac mini M4 上，让角色聊天可以使用已微调的胡桃音色朗读新回复，沿用系统识别、DeepSeek 文字聊天、共享双窗、完整回复首次保存后朗读、主动停止及既有安静/生命周期规则。App 负责启动和停止独立引擎，用户无需每次先开终端服务。

成功标准：

1. 将稳定的本机引擎准备到项目之外的运行数据目录；日用不再依赖 `.build` 或当前源码 checkout。App 仍可独立使用系统语音。
2. 导入一套本地语音文件夹，预览后确认复制；按皮肤 `manifest.id` 明确绑定当前角色。切换角色会采用该角色的绑定，未绑定的角色使用原系统音色。
3. 首次试听或朗读才启动引擎，显示启动、生成、播放和失败状态。生成在独立进程，阻塞计算不能占据 App 主线程。
4. 用户停止、录音前、换角色/同 ID 换肤、安静、聊天隐藏/最小化、离页、菜单/模态、睡眠和退出均能撤销旧请求；取消后不会迟到播放或回退发声。
5. 本地尚未开始播放时失败，可明确显示本次系统音色回退；已经播放后发生错误不重读整条。原聊天内容与保存事务不受语音失败影响。
6. 保留主配置 schema13、角色档案 v2、现有 `AI/voice.json` schema1、全部旧语音偏好与钥匙串标识。测试和试运行使用隔离目录，不用个人聊天或正式 API 密钥。

现有胡桃证据是：39 条原始音频中选 14 条、约 69 秒作 S2 微调，GPT 继续使用 s1v3 底模；e1/e2 各 172,756,275 字节。用户对两句试音反馈“接近胡桃了，第二轮和第一轮都差不多”。这不代表全部文本、完整复刻或生产验收。首次接入候选选 e1 属作者提案，e2 与仓库外备份继续保留，不重训或覆盖权重。

本版不做持续录音、云端音色、自动语音发送、边接收 DeepSeek token 边朗读、多角色同时发声、声音口型同步、在线语音商店或模型自动更新。不交付陌生 Mac 免 Python 的通用运行时；Intel App 保留系统语音，本机 ARM 引擎不作为 Intel 引擎发布。

## 2. 已讨论方案与选择

| 方案 | 取舍 | 选择 |
| --- | --- | --- |
| 当前 M4 的独立托管引擎，语音数据与 App 分开 | 可复用已验证模型和本机 Python 条件；需要一次明确准备环境，依赖当前机器的 Python 与原生库 | 用户明确选择本版先做这一档 |
| 同时提供陌生 Mac 免 Python 的可搬移引擎包 | 需要 Python 分发、原生 wheels/动态库、最低系统、搬移、签名和外机安装验证 | 用户明确选择后续再做 |

作者采用受 App 管理的独立 Python worker，通过本地管道通信；无需用户手动启动 HTTP 服务，也不监听端口。App 保持 Swift 6/AppKit 与现有系统框架，Python/ML 依赖只属于可选独立引擎，不进入 App 的链接依赖或普通安装包。引擎准备工具和适配器源码进入 Git，模型、运行环境与生成音频不进入 Git。

## 3. 本机运行环境与数据布局

运行数据相对于实际 `settingsURL` 的父目录保存，隔离配置同时隔离所有语音数据：

- `LocalVoice/Engine/Versions/<uuid>/`：版本化的固定 GPT-SoVITS 源码、共用底模、中文前端及独立 Python 环境；引擎描述只指向完整准备成功的版本。
- `LocalVoice/Voices/<libraryUUID>/`：确认导入后的语音包原字节副本。
- `LocalVoice/index.json`：语音库索引及角色绑定，schema1，最多 64 KiB。
- `LocalVoice/Cache/`：受控引擎缓存；生成 WAV 使用单独的私有临时任务目录，不作为长期记录。

缺失数据不在 App 启动时创建，不自动安装、联网或加载模型。普通默认位置为 `~/Library/Application Support/YeShunguangPet-macOS/LocalVoice/`，但实现不得硬编码个人路径。

仓库提供明确执行的开发准备工具：读取已验证实验源码/底模/候选与版本记录，检查摘要和本机架构，在稳定目录新建 Python 3.12 环境并按固定版本准备依赖。不得原样搬移旧 venv：现有 shebang、pyvenv.cfg 与 Homebrew 链接不保证可搬移。允许显式准备阶段使用依赖下载缓存和包源，日志不记录聊天或密钥；App 自身不运行 pip，不在第一次点击朗读时下载依赖。实际安装失败必须保留原实验环境和旧 App，不能靠复制 venv 后改名宣称准备成功。

引擎准备在独立的新版本目录完成，完整依赖/源码/公共资源检查后原子切换描述文件，已有有效运行目录不原地覆盖。venv 一开始就在最终版本路径创建，不能准备后再次移动而破坏 shebang；失败版本保持未启用并明确清理状态。准备/切换引擎前要求目标 App 完全退出，工具只核对和提示，不盲目结束进程；本轮交付按准确 App 路径正常退出后准备。首次不做通用引擎导入 UI；以本机准备工具提供稳定环境，语音页显示是否就绪和可读的修复说明。运行时仅验证并调用这个固定配置，不从语音包读取可执行程序或脚本路径。

公共资源包括 s1v3、中文 RoBERTa、HuBERT、说话人模型、完整 G2PW 数据和 fast-langdetect 数据。推理不复制训练 ASR、判别器、训练样本和两个对照权重。源版本固定 `b4570b876f5c086819ba84e3215472733c6a7b70`，保持上游源文件字节；本项目适配器负责路径映射与临时配置，禁止写回上游默认配置。所有必需模型先预检；运行时显式离线并把 HF、Numba、matplotlib 等缓存放入受控目录，缺失资源失败而非临时下载。首版只承诺中文路径，不能将本机中文试音扩大为多语言支持。

本机引擎仍依赖本机可用的兼容 Python/原生库，Homebrew 更新可能要求重新准备；界面应明确这是“当前 Mac 的本地引擎”。此风险不由 App ad-hoc 签名或数据摘要消除。

## 4. 语音包与角色绑定

首版接受一个本地文件夹，固定包含 `voice.json`、`s2.pth`、`reference.wav`；不接受 ZIP、包内代码、任意 Python、远端 URL 或整个实验目录。交付准备工具输出可见的 `dist/语音包/胡桃-试用-e1/` 文件夹，方便文件面板选择；它仍被 Git 忽略。

`voice.json` schema1 严格字段记录：包 ID、显示名、语言、引擎 profile、S2 与参考音频的文件大小/SHA-256、参考文本及可选建议角色 ID。引用仅允许上述固定文件名。显示名最多 80 UTF-16，包 ID 和角色 ID 复用现有皮肤 ID 规则；语言首版为 zh-CN，profile 固定当前 v2ProPlus CPU；参考文本非空、最多 400 UTF-16，无不允许控制字符。JSON 最多 16 KiB，拒绝重复键、未知版本/字段和非法类型。

模型最多 256 MiB；参考 WAV 最多 1 MiB，必须为可完整读取的 32 kHz/单声道/16 位 PCM，时长 3–10 秒。文件夹只接受三份上述普通文件，可忽略但不复制 Finder 的 `.DS_Store`；拒绝未知文件/子目录、根与包内链接及 `..` 跳转，固定路径解析后必须留在根内。系统外层临时目录的标准路径别名可规范化，不把 `/var` 的系统别名误判为包内链接。检查声明大小、实际读取上限和 SHA-256，再向私有 staging 复制并复核，源变化不产生部分导入。大文件读取/摘要/复制在后台，不加载模型作预览。参考音频预制，运行时不依赖实验脚本中硬编码的 FFmpeg 路径。

SHA-256用于字节完整性，不作为来源认证。当前交付只提供已核对的胡桃 e1 包；UI 显示包名、引擎和来源提示，用户只应确认信任的本地模型。导入文件夹不能执行包内脚本；上游权重读取仍需信任模型来源，不能把普通 Python 子进程称为系统沙箱。本版不新增公开下载入口。

导入先预览再确认，只复制与登记，不自动启用全局语音、不立即发声、不自动绑定。语音页提供“当前角色音色”，从“系统中文音色”或已导入项选择，再点“应用当前角色音色”；以完整角色上下文冻结，明确保存后生效。建议角色 ID 只帮助展示，不替用户确认。原系统音色选择继续作为该角色使用系统语音/失败回退时的选择。

索引最多 16 个语音包、16 个角色绑定；使用库 UUID 区分同名包，相同完整内容可复用既有副本。按 `manifest.id` 绑定，不按皮肤导入 UUID、显示名或临时 skinRevision 存档；当前播放仍核对完整角色及 skinRevision。选择系统音色会清除该角色绑定，不删除模型。首次交付 e1 是候选，用户确认绑定后才成为当前角色实际选择。

允许查看、刷新与确认删除未绑定的语音包；当前或其他角色仍绑定的包不能删除，先解除绑定。坏包隔离并显示原因，不能让一个损坏项阻断整个语音页。引擎/包正在使用、导入/删除/确认模态或退出时不允许变更；取消未确认任务不提交，接受的复制/索引事务纳入正常退出等待。索引写失败保留旧绑定/副本和可重试意图，不留下“UI 显示已应用而重开失效”的假成功；复制后尚未登记的副本有独立待清理状态，退出失败可见，不批量清理用户其他模型。

## 5. 朗读选择、上限与失败回退

保留 `AI/voice.json` 的启用、自动朗读、系统音色及语速。角色绑定独立保存在 index，不扩展旧 voice.json，避免无关迁移；“应用语音设置”与“应用当前角色音色”为两个明确保存动作，不伪装多文件原子事务。新绑定写入复用同一聊天 FIFO 的独立事务，正常退出可重试，仅落盘而不补播。索引损坏时保留原字节、暂停本地绑定并提示可备份重置；系统语音和文字聊天仍按原有效偏好工作。

输出选择先看当前角色绑定，再决定系统或本地引擎；本地输出不能因系统中文音色列表为空而被提前拒绝。系统音色枚举变化只影响系统输出。UI 展示实际使用的输出来源，包含“本地胡桃”“本次回退系统音色”以及启动/生成/播放中，不能把选中的本地项当作已经成功发声。

自动朗读沿用完整普通回复首次成功保存后、最多 600 UTF-16 的现有按句截取。操作卡、记忆提炼、不完整回复、失败、本地保存重试不自动发声。本地单次首版最多 600 UTF-16；主动朗读超过该长度时，在开始前明确提示本次使用系统音色读完整回复（仍遵守原 8000 上限），避免静默截断。没有系统音色时说明原因，不自动截断或重新生成文字。该限制及回退信息在语音页可见。

原语速 0.35–0.65 保持；系统照旧，本地映射为 speed_factor=rate/0.5，即默认 1.0、范围 0.7–1.3。两种引擎感知速度不保证相同；不另改文字、人设或 DeepSeek 请求。

本地启动、资源检查、生成或播放准备失败，在尚未开始可闻播放且用户意图仍有效时，终止本地任务并确认清理，再至多回退一次系统朗读；提示具体本地失败类别与实际回退来源，不改变已保存绑定。系统音色也不可用则停止并提示手动修复。已经开始播放后失败，不自动换音色重读；用户可手动重试。取消、换角色、安静、离页、睡眠、退出等正常中止绝不触发回退或补播。

## 6. Worker、播放与取消合同

一个共享输出路由器组合原 `NativeSpeechOutput` 与新的本地输出服务；两个窗口复用唯一 ChatVoiceController，不各自启动进程。接口传入输出选择及冻结的角色/请求 ID，而非把本地包伪装成 Apple voiceIdentifier；原系统声音接口仍可独立测试。

worker 在首次有效本地输出时异步启动，固定解释器、固定适配器、参数数组及工作目录；不用 shell 拼命令，不把聊天文字放入命令行或环境。协议为有界 UTF-8 JSON 行，固定版本和请求 ID；只提供 ready、generate、result/error、shutdown 等必要命令。不监听 HTTP 端口。stdout 专用协议，上游杂项输出丢弃或隔离，持续排空 stderr 但不记录其可能包含的文本；每行最多 64 KiB，异常/过量输出终止进程并按失败策略处理。

worker 内保持一个固定角色模型，CPU/float32/4 线程、中文、batch1，关闭 CUDA 加速与流式。原生层持有一个请求，拒绝重入，重复点击先通过同一停止屏障；换角色或模型重启 worker，防止多个大模型同时驻留。正常任务结束后可保留该模型，180 秒无任务后退出释放内存；App 打开或后台待机不周期轮询。退出/禁用/睡眠时立即清理，不等待空闲计时。

首版先生成整条有界 WAV 再由 AppKit/AVFoundation 播放，不宣称实时流式。启动 ready 上限 45 秒；ready 后单次生成上限 120 秒；仅在启动/生成期间有界采样准确子进程 RSS，观察到超过 8 GiB 就终止并提示，不能把采样阈值宣称为无超调的系统内存硬限制。监控异步处理，不能 waitUntilExit/readToEnd 阻塞 MainActor。输出 PCM WAV 最多 32 MiB、最长 240 秒；父进程指定私有任务目录与固定输出路径，结果只回任务 ID/成功元数据，拒绝越界、链接、非预期格式、超限和空输出。播放前使用有界不可变快照验证音频。临时目录 0700，音频不命名为聊天内容；完成、失败和取消及时删除，清理失败可见。缓存不得记录聊天文本或生成音频历史。

停止是资源屏障：同时停止原生播放器、撤销代次和结果，并终止本 worker；不能仅依赖上游 TTS.stop 标志。先向准确的子进程请求退出/终止，2 秒后仍存活则只强制结束本服务拥有的该进程，继续等待最多 2 秒并回收句柄/管道。不得按进程名杀其他 Python。确认播放器和进程都停止才返回 true；旧 terminate/result/error 不能清除新请求。

未确认停止时显示通用“语音输出尚未确认停止”与重试入口；新录音、朗读、试听、回退均被屏障阻止。录音前必须等屏障成功，不在等待中申请麦克风权限或让模型继续计算。worker 监视父管道失联并自行退出，验证父进程异常结束的清理；禁止把“丢弃结果”记为进程已停止。

ChatController/AppDelegate 正常退出增加独立语音资源等待，不只检查磁盘 FIFO；开始退出立即撤销语音意图，异步等待清理，失败允许重试或取消退出，不以无限等待卡住 UI。若用户明确继续退出，记录清理结果的实际边界，不声称未确认资源已结束。取消退出不恢复朗读或旧生成。

## 7. UI 与已有生命周期

完整窗“语音”页保留原控件，增加引擎状态、当前角色音色、语音包列表、选择文件夹/预览确认、应用绑定和删除入口。状态和错误可滚动，440×420 最小窗仍可达，轻窗 320×240 继续使用原朗读/停止按钮并共享输出来源与阶段；不在轻窗安装环境。界面直接说明本地首次启动会等待、单次长度和当前回退；不要求用户理解 Python 类名或模型张量。

新语音设置不改录音规则：45 秒主动录音、5 秒收尾、优先本机识别、用户允许后本次新录音可 Apple 联网、文字检查后手动发送。DeepSeek 继续只接收原文字链路；本地语音合成不向 DeepSeek 上传音频或增加模型请求。

沿用既有生命周期：完整/轻窗正常交接继续同一活动；仅隐藏桌宠不停止独立可见聊天；角色/同 ID 皮肤修订变化、聊天真正关闭/最小化/App 隐藏、离开页面、菜单/阻挡模态、安静、睡眠、禁用和退出按原规则停止输出，不补播。引擎准备、包导入、预览/确认、索引写入纳入清晰互斥门控，不让回调在已结束窗口启动旧生成。输入法 marked text 与原窗口交接规则保持。

## 8. 验证及本地交付

自动验证使用临时 settingsURL/LocalVoice、假凭据/网络、假进程与小型合成音频，不加载正式模型或申请真实麦克风权限。新类型/文件明确登记 Xcode 的 App 和无 host 测试 target；Python 适配器的协议和边界可用替身模型离线验证。模型文件不进入测试夹具或 CI Artifacts。

必须覆盖：
