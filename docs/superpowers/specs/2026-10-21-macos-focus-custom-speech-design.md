# 0.1.15 自定义台词与专注计时设计

日期：2026-10-21（Asia/Shanghai）。基线：`d837afb`（0.1.14）。

用户选择D＋F，明确专注与休息手动衔接，随后批准会话设计并说“设计好，你就执行，我睡觉了”。这条直接授权覆盖逐阶段等待设计及计划审批，保留书面记录、自审、本会话实施、回归和独立最终评审。沿用独立Mac仓库原地开发，不另建工作树；仅本地提交及交付，未经新的明确指令不推送、打标签或发布。

## 目标与范围

让单角色桌宠具有可定制的回应和实用的单段专注/休息计时，同时保留既有偏好、真实皮肤及非激活角色窗口。首版交付0.1.15/build16，Swift 6、AppKit及SwiftUI，macOS 15+，arm64日用、x86_64实验交叉构建，无新增依赖。

1. 当前角色可分别编辑点击、拖动、专注完成、休息完成四类台词；可恢复皮肤原台词。
2. 专注默认25分钟、休息5分钟；专注1–120、休息1–60整数分钟；开始、暂停、继续、重置及完成状态可见。
3. 每段完成后等待用户手动开始下一段；没有自动循环。退出放弃当前段，重开只恢复已保存时长与台词。
4. 专注运行时临时暂停注视、自动动作、走动与台词；暂停、结束或重置解除该暂停，不改变手动安静开关。
5. 隐藏、切页、关闭设置或打开菜单不暂停计时；系统睡眠时间计入，唤醒后最多结算一次，不连续补播多个阶段。
6. 完成时，在角色可见、已醒、未手动安静且没有菜单/设置/鼠标操作或退出阻挡的情况下播放一次动作；启用“显示互动台词”时再显示对应气泡。其他情况只保留菜单和专注页的完成状态，不强行显示角色或抢焦点，不积压提醒。

首版不增加系统通知、声音、专注历史、统计、云同步、悬浮计时窗、系统专注模式控制或防睡眠断言。计时不是屏幕使用时间监控。Windows及Minimal Sleep仅只读参考，真实JSON/PNG字节不变。

## 采用的结构与参考

采用“设置专注页＋两个原生菜单子菜单”，复用现有设置窗口和暂停门控；独立悬浮窗会增加焦点、空间与窗口管理，留待实际需要。台词在现有互动页编辑。D和F共享四类台词及配置迁移，按依赖分任务，不分别新增存储或提醒系统。

Windows `Focus/CompanionSession.cs`的ready/running/paused/completed和手动进入下一段为行为参考；`PetSystem/PetSpeech.cs`已定义四类默认台词。Minimal Sleep的iOS `SleepTimerPolicy.swift`表明可以使用可注入单调时钟和绝对期限，参考做法而不复制项目代码、音频逻辑或签名配置。

| 单元 | 职责 |
| --- | --- |
| PetCore `PersonalSpeech` / `SpeechLines` | 四类文本、默认与个人覆盖解析、验证和总量限制 |
| PetCore `FocusTimer` | 无窗口/Timer/存储的纯状态机，注入单调时间，唯一完成事件 |
| `SettingsStore` / `PetPreferences` | schema10及1–9迁移，原子保存全部偏好，坏文件保护 |
| `PetSession` | 新偏好保存成功后生效；区分手动安静和专注暂停；用现有角色/气泡完成回应 |
| `FocusController` | 主线程持有纯状态、一个独立一次性调度器、观察机器睡眠、发布界面快照 |
| `FocusMenus` / `FocusSettingsView` | 两个独立原生子菜单与一个设置页，共用同一个FocusController |
| `PersonalSpeechEditor` | 当前角色草稿、应用/恢复、清除已保存角色的覆盖；不读写皮肤素材 |

FocusController由StatusBarController持有，与SettingsModel一样不依赖设置窗口是否已创建。设置窗口只观察共享对象，关闭不销毁计时。倒计时通知只更新专注视图/菜单，不每秒触发现有SettingsModel.refresh、登录项查询或缩略图解码。

## D：个人台词合同

个人覆盖键使用皮肤清单稳定的`manifest.id`，相同ID的导入副本共用台词，重新导入仍生效。界面展示当前名称和ID，避免和导入副本UUID混淆。删除皮肤不自动删除个人台词；已保存覆盖可按ID清除，不删除素材。

每个覆盖明确包含四个数组，整组优先级为个人覆盖→皮肤speech→默认台词。皮肤speech省略/null用默认；显式空数组不回退。编辑草稿先填充当前有效台词，每行一句，忽略空白行并裁掉句子两端空白；空编辑框保存为空数组，表示该类不说话。每类最多8句，每句1–80个UTF-16单元、无控制字符；最多16个角色，总文本不超过8192个UTF-16单元。整体配置仍不超过64KiB。

只有点“应用台词”才保存。保存失败保留磁盘与当前有效覆盖，显示原因并保留草稿；恢复原台词删除当前角色覆盖。切换角色、离开互动页或关闭设置丢弃未应用草稿；编辑时捕获目标ID，不能把旧角色草稿应用到新角色。皮肤忙碌、模态或退出期间禁用编辑提交。

“显示互动台词”仍默认关闭并控制四类气泡。点击/拖动沿用30秒全局冷却、6秒气泡和避免连续同句。两个完成事件可越过普通互动冷却；成功显示仍更新冷却，防止完成后立即被点击台词覆盖。无空间显示时不消耗冷却；完成动作可独立于台词开关执行。四类默认文案使用既有Windows行为文案，属于原设计继承，不修改皮肤资源。

## F：纯状态与时间合同

阶段为focus/rest，状态为ready/running/paused/completed。初始ready/focus。开始设置`deadline = now + duration`，剩余时间由期限推导，不每秒递减。暂停保存剩余，继续重建期限；重置取消期限并回ready/focus。完成时期限清空、剩余为零并只产生一次阶段事件；完成专注后的开始按钮进入休息，休息完成后开始专注。

在过期边缘按暂停或旧的开始命令时先结算原阶段，不能意外启动下一段。界面命令捕获操作种类及状态转换代次；即使计时先到期，旧“暂停”也不能被重新解释为“开始休息”。代次只在状态、阶段或时长变化时增加，不随每秒刷新变化。重复Tick、重复唤醒或晚到Timer不会重复完成。重置与退出直接取消，不伪造一次完成。运行和暂停期间不能改时长；completed需先重置再改。配置保存成功后才更新ready时长；失败不改变当前时长。

使用现有ContinuousClock来源（睡眠仍递增），不以系统墙钟计算倒计时；改日期/时区不改变剩余。只保存两个默认时长，不保存运行中的期限或已完成数量。

FocusController复用FrameScheduler类型但持有独立实例，因为角色动画隐藏/睡眠会停，而计时有独立生命周期。无可见计时界面时，只安排阶段截止的一次性唤醒；专注设置页可见或相关菜单正在跟踪时，最多每秒刷新一次显示并同时保留到期结算。ready/paused/completed、机器睡眠和退出协调期间无计时器。机器唤醒或取消退出后按期限结算并重新安排。显示器熄灭不等同于暂停计时。

## 安静与完成回应

PetSession保留手动`isQuiet`真值，另有`focusQuiet`。被动行为和台词用二者的或值判断；菜单安静勾选仍表示用户手动开关，旁边的专注状态解释临时暂停来源。专注仅在running/focus持有暂停，休息和paused不持有；开始/结束不会把手动安静关掉，也不持久化临时状态。

进入专注暂停时沿用cancelInput收起气泡、停止走动并冻结自动行为等待，不改用户的注视/动作/走动/台词开关；解除专注暂停时仅重新调度，保留正在进行的手动输入。计时本身不进入皮肤isBusy。手动拖动/单双击、隐藏/召回、换肤和位置锁定继续按已有规则；完成动作不移动角色，位置锁定不阻止安全的完成回应。

Controller先提交completed并解除focusQuiet，再请求角色完成回应：focusCompleted挥手、breakCompleted跳跃，动作仍走原回退。被菜单、设置、鼠标操作、隐藏、睡眠、手动安静或退出挡住时丢弃这次视觉回应，完成状态一直保留到用户操作。没有异步待播队列，不在解除隐藏后突然补播。

## 配置、界面与退出

schema10在preferences增加`focusMinutes`、`breakMinutes`、`speechOverrides`。为schema9保留专用旧偏好结构，旧1–9迁移为25/5和空覆盖，保留全部旧偏好、位置、选择及快捷键。schema10缺字段、非法数值/ID/句子/容量、重复键或未知版本保护原字节；仍通过已有显式备份重置解除保护。

新时长与覆盖走专用PetSession提交方法：构造保留所有其他字段的候选，先SettingsStore.save，成功后替换有效偏好。普通setPreferences禁止顺带更改这些字段或快捷键。配置受保护时仍可使用默认时长计时，但不能假装保存成功。

设置新增“专注”Tab：阶段、状态、mm:ss、两项整数分钟设置及“应用时长”、开始/暂停/继续/下一段、重置；运行/暂停/完成期间时长只读。现有最小520×480窗口中可滚动且按钮可达。个人台词编辑在互动页，展开时滚动；关闭/切页丢弃草稿。

菜单栏和角色右键各有独立“专注计时”子菜单，共用状态，显示阶段/剩余、主要操作、重置和“专注设置…”。所有父子菜单共同进入既有暂停集合；有菜单显示时不会提前恢复被动行为或快捷键。模态/退出期间禁用命令，菜单跟踪仍允许到期结算，不触发抢焦点提醒。

退出协调先标记terminating并取消计时调度，保留期限以便用户取消退出后重新结算；取消退出时根据实际窗口可见性及当前页恢复倒计时显示消费者，其他页或已关窗仍只安排截止。确认退出再dispose、移除观察者、取消timer及解除临时暂停。只清除本次运行状态，不登记登录项、修改个人快捷键或额外联网。
