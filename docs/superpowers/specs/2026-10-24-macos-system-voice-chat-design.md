# 系统中文语音交流设计

日期：2026-10-24（Asia/Shanghai）。基线 `0ae7f82c56fbb4481ce4ed28fc57802bb9e98bf2`，0.4.0/build26；用户已反馈本机整体验证通过，main 与开发分支已普通同步，两路 CI 的427项原生、13项离线发版、13项分发及双架构产物通过。整体反馈不替代各系统场景专项验收。

状态：用户选择下一版 C「语音交流」，随后明确「系统中文音色打通」，并选择「本机识别不可用时，提示后可选择 Apple 在线识别」。交互、保存、默认值和版本0.5.0/build27最初由作者提出；用户于2026-10-24明确认可整份书面设计，随后明确「认可计划，按本会话方式实施」。沿用本会话原地连续开发、一次最终独立整体代码评审；产品实施已获准，回归及本地交付按实际结果补记，未授权本版推送、标签或 Release。

## 1. 目标与成功标准

在已有完整聊天窗与角色旁轻聊天中，以系统中文识别和朗读完成「说话 → 检查文字 → 发送 → 听回复」，继续使用既有 DeepSeek、人设、12轮完整问答、已确认长期记忆和操作确认卡。

1. 用户主动开始/结束一段录音，实时看到识别预览；识别结果插入原草稿的选中位置，用户仍能修改，再用原发送按钮或⌘Enter发送。结束录音、静音停顿和权限授权均不自动发送。
2. 启用语音后，可自动朗读成功保存的完整普通回复，也可主动朗读最近一条已保存回复；随时可以停止。录音、朗读及聊天状态在轻/完整窗间共用。
3. 优先要求本机中文识别。本机不支持或明确不可用时，停止本次尝试并提示；用户可选择重新录制，明确允许「本次使用 Apple 在线识别」。不无声切换，不把先前录音回传或自动重试。
4. 权限拒绝、没有输入设备、中文音色缺失、服务不可用、断网或换设备等失败均可见；原草稿和纯文字聊天仍可使用。
5. 停止、关窗、换肤（包括同ID新修订）、睡眠、退出等不会留下麦克风、旧音频队列或晚到识别覆盖；窗口正常交接继续同一次语音活动。
6. 交付目标为0.5.0/build27、macOS14+、arm64日用与实验x86_64包；保持主schema13、角色档案v2，升级时不改写已有AI档案，正常聊天仍按原规则保存。自动验证与真实发声、麦克风、Apple服务、DeepSeek、物理输入及Intel验证分别记录。

首版由用户点击「开始说话」，再点「结束识别」，每段最长45秒；不是持续监听或语音唤醒。没有云端角色音色、声音克隆、语音自动确认操作、长录音转写、系统音频采集、录屏或外部App控制。App不保存录音及生成的音频文件，不在识别之外上传音频；DeepSeek只收到用户主动发送的文字和原有提示上下文。

## 2. 已讨论方案与选择

| 方案 | 取舍 | 选择依据 |
| --- | --- | --- |
| Apple Speech识别＋系统中文朗读＋既有DeepSeek文字链路 | 无需另配语音服务凭据；可用音色和识别能力依设备、语言及系统而异 | 用户明确选择系统中文音色，作者采用此原生实现 |
| 另接云端自然/角色风格音色 | 可以追求不同的音色效果，需另做服务选择、试听、费用和网络方案 | 已向用户说明，本轮未选 |

识别路径也已向用户说明：严格只用本机，或在本机不可用时提示并让用户选择Apple在线识别。用户选择后者。作者提议在线选择只对本次新录音有效，不跨录音或重开记住；后续若日用反馈表明重复提示影响使用，再单独调整。

使用覆盖macOS14的 `SFSpeechRecognizer`、`SFSpeechAudioBufferRecognitionRequest`、`AVAudioEngine` 和 `AVSpeechSynthesizer`；不采用要求较新系统的SpeechAnalyzer，不增加第三方包或独立语音模型。Swift6.4本机与Swift6.3.3云端均需实际编译验证。现有Minimal Sleep为iOS项目，仅参考音频取消/存储模式，其AVAudioSession实现不直接移植到Mac，仓库保持只读。

## 3. 交互、权限与识别

### 3.1 窗口与开关

完整聊天保留四个原页，新增「语音」页。提供「启用语音输入与朗读」（默认关闭）、「自动朗读新回复」（默认选中，但受启用开关约束）、已安装的系统中文音色、语速、试听、状态与错误。升级或首次打开聊天不会发声、录音、申请权限或请求Apple/DeepSeek服务；用户先启用语音，再主动录音或试听。禁用时立即停止语音活动，不能等保存结束才关闭。

两个对话界面加入「开始说话/结束识别」「取消录音」「朗读最近回复/停止朗读」的明确入口；语音关闭时以「语音设置…」引导到完整窗的语音页。轻窗以独立紧凑一行或两行呈现语音按钮，状态/识别预览位于可滚动内容中，仍满足320×240最小尺寸；发送、停止及操作卡不得被挤出可达范围。完整窗保留440×420最小尺寸和滚动。

录音/等待最终结果期间，输入框暂不可编辑、不可发送/提炼/确认操作或发起第二段录音；保留结束及取消入口。开始录音要求当前角色/档案/连接已就绪、AI开启、没有请求、待确认操作、待存问答/记忆、其他资料写入或阻挡模态，不因草稿为空而禁用。记忆候选若已生成且无待存变更，可以保留原冻结来源；录音期间不能确认候选。输入法有marked text时不开始录音、不交接或强制提交；不增加全局键盘监听和快捷键配置。

### 3.2 权限与数据流

只在用户点击开始录音时检查/按需请求麦克风与语音识别权限，补齐两个用途声明。启用开关、打开页面和朗读不请求麦克风权限。权限回调不保证主线程，必须安全交接MainActor并核对角色/会话代次；用户取消、关窗或换角色后，即便随后授权也不能启动麦克风。

两项权限已允许后，重新检查设备、当前窗口、可用状态及录音意图才启动。拒绝/受限制时显示具体类别及系统设置中的处理路径，不循环弹权限、不改系统TCC数据库或自动重置权限。权限请求期间可取消录音意图，系统自身弹框的寿命由macOS管理。

识别语言首版固定普通话 `zh-CN`。本机路径显式设置 `requiresOnDeviceRecognition=true`，先检查 `supportsOnDeviceRecognition` 与服务可用性。本机能力/资源不足时提示「本机识别当前不可用」，不把所有错误归因为断网或宣称可自动下载模型。用户选择「允许本次在线识别」后，以「允许联网识别」标识开始一段新录音、设置非强制本机识别；说明系统可能将音频交给Apple处理。这个标识代表用户允许的模式，不声称已经确认系统实际选择了远端处理。授权仅覆盖该段，任何错误都不自动追加第二次服务请求；取消不能撤回服务已经收到的音频。

使用系统当前默认输入设备。录音前核对有效采样率与通道，设备无效时不安装tap；捕获设备切换、engine配置变化及运行错误时停止，提示用户检查系统声音输入设置再重试，不自动重启捕获。工具环境的system_profiler本次返回空设备列表，仅是调查工具结果，不能据此断言用户Mac没有麦克风或已完成真实输入检查。

### 3.3 录音、结果与草稿

开始时冻结完整ChatCharacter（含skinRevision）、语音代次、当前草稿修订/字节及按字素边界夹取的选区。识别预览独立显示，不用partial结果反复改写共享草稿。录音时显示明显的「正在听」及有界时间/状态；每段45秒到期等同用户点结束，只停止输入并等待最终结果，不自动发送。结束后最多等待5秒最终结果，超时就终止该任务。

最终成功后，以冻结选区替换文字，保留前后原草稿；结果非空、与原文合成后不超过原2000 UTF-16上限，且角色、语音代次和草稿修订/原文仍匹配才一次写入setDraft。超长不静默截断、不覆盖原草稿，预览保留并显示原因。原输入草稿不落盘规则保持。

没有声音、识别失败或超时不自动接受partial。若已有有效预览，可在本次上下文中点「使用已识别文字」，按相同修订、长度和选区检查手动插入；空白或超长预览不能插入。取消、换角色或真正关窗清除这份预览，原草稿保留。任意晚到partial/final/error均须核对完整上下文和代次，防止同ID换肤及草稿改回原样的ABA覆盖。开始新录音先明确放弃上一份未接受预览。

## 4. 朗读与打断

系统已安装的Apple中文音色供用户选择；不申请Personal Voice授权、不调用第三方语音提供者。默认优先可用zh-CN音色。所选音色缺失时显示实际使用的中文回退音色，不覆盖保存的选择；没有可用中文音色则禁用朗读并提供系统设置中的下载指引，文字与识别仍可使用。设备/音色变化通过系统通知和主动操作时刷新，不增加后台轮询。

自动朗读只在普通模型回复完整结束且首次成功本地保存后触发，一次问答最多一次。复用既有反馈的事务边界，但语音与角色挥手/气泡的显示条件分开；隐藏桌宠而聊天窗可见仍可朗读。操作提议、App操作回执、记忆提炼、未完成流、失败回复、保存失败及其本地重试不自动朗读，不因重开、唤醒、恢复显示或改开关而补读。

自动朗读需语音与自动开关已生效、当前普通回复所属完整角色/请求仍匹配、聊天对话页实际可见、没有菜单/阻挡模态/录音、未睡眠退出且未处于有效安静（手动或专注安静）。这些条件在触发时及状态变化时检查：不满足就跳过/停止，不排队等恢复。离开对话页、最小化或App隐藏会停止；窗口失去key但仍可见不单独停止。开始新发送、提炼、换角色、停止或关闭AI也停止旧朗读。

自动朗读最多600 UTF-16的回复开头，按完整字素并优先句末截取，界面说明长回复只读开头、完整内容保留在文字中；不为生成摘要额外请求模型。主动「朗读最近回复」读取当前角色最新一条已保存assistant文本（包括明确标识的本地回执），最多原8000 UTF-16，不读流式partial；不形成新问答或新API请求。试听仅读固定中文短句。手动朗读和试听同样遵守有效安静和生命周期阻挡，原因可见；用户先取消安静后再主动播放。

所有入口共享一个合成器/当前朗读令牌，新的朗读替换旧朗读，不累积历史队列；用户点停止立即清除当前及队列。开始录音先停止朗读并确认输出已停止后才装tap，失败则不录音，避免录下自身回复。App自身专注提示音在录音/等待识别期间抑制且不补响；不改变专注状态、完成统计和安静语义。其他应用的声音由系统和用户输入环境决定。

首版不边生成边朗读，不做双向同时收听、声学回声消除或口型同步。系统合成回调与识别一样检查令牌、完整角色和生命周期，旧cancel/finish不能清除新一段的状态。

## 5. 状态、组合与生命周期

共享语音控制器位于Mac层，由唯一ChatController持有/组合；两个窗口只呈现同一状态并转发明确命令。录音权限、录音、收尾、可手动接受的失败预览及朗读状态与现有ChatState分开，不能把「语音正在识别」当模型已发送或已生成。服务及权限边界可注入替身；自动测试默认不创建真实录音/合成请求。

| 事件 | 语音处理 | 原聊天处理 |
| --- | --- | --- |
| 开始说话 | 先终止朗读；冻结上下文并按权限/能力启动一段捕获 | 不发送，不改历史 |
| 结束识别/45秒到期 | 移除tap并结束输入；最多5秒等final | 成功只写草稿 |
| 取消录音/统一停止 | 取消捕获、识别、收尾和朗读；清预览 | 统一停止仍沿用取消未接受模型结果，已接受写入继续 |
| 完整⇔轻窗交接 | 同一语音会话继续、预览/选区保留 | 原草稿/请求/卡片不变 |
| 关窗、换肤、睡眠、开始退出、dispose | 撤销全部语音代次、停止资源、不自动恢复 | 已接受问答/记忆/回执写入照旧保留 |
| 最小化、App隐藏、离开对话页、菜单或阻挡模态出现 | 停止捕获及朗读，原草稿保留；主动试听只在语音页允许 | 按既有规则继续或取消模型请求，不由语音扩大取消范围 |
| 有效安静开启 | 停止朗读，不自动恢复；用户主动录音仍允许 | 原专注/手动安静保持 |
| 仅隐藏桌宠/窗口失去key | 不单独停止语音 | 原窗口独立规则保持 |

取消是幂等操作，覆盖权限未回、engine未启动、tap已移除、收尾中以及晚到事件。录音输入回调不持有窗口或在音频线程碰UI；共享request/engine跨回调的同步由适配层处理，销毁后不能向已结束request继续append。具体锁/队列封装由实施者决定，必须符合Swift6并发与设备停止约定。

窗口交接不能经过会触发语音取消的中间「全部不可见」状态；协调器需以交接事务合并visibility通知，并在最终状态刷新。检查目标窗口及全局门控通过后才隐藏原窗口；同处一并修正0.4已记录Minor（设置sheet阻挡时full内部切quick暂时隐藏两窗），增加直接回归，不扩展为无关窗口改造。

## 6. 偏好、兼容与失败

新增独立 `AI/voice.json`，schemaVersion1，最多8KiB，保存全局语音启用、自动朗读、首选音色标识与语速。默认值为false/true/nil/系统默认语速；语速限定0.35–0.65，标识非空时最多256 UTF-16，无控制字符。严格检查版本、字段、布尔与有限数值、重复键和普通文件；缺失文件返回默认而不写盘，非法文件保留原字节并保护，仅语音禁用，其他聊天继续。

启用/音色/语速/自动开关通过明确「应用语音设置」先保存再生效；禁用按钮必须先立即停止语音并本次关闭，随后保存，失败明确显示重开可能恢复原偏好。本次临时禁用直到用户再次明确成功启用，不因其他设置保存或失败重试自动复活。其他失败候选保留供本地重试或放弃，不在重试后自动开始录音、试听或补读。受保护文件提供只针对voice.json的备份重置确认，不重置connection或角色档案。

偏好写入复用AI的后台工作者与既有有序FIFO，已经接受的偏好事务纳入正常退出等待及失败选择；不另建与聊天互相覆盖的写队列。旧主配置schema13、connection格式、角色v2、人设、记忆、12轮裁剪、Keychain服务/账户标识和原皮肤保持；旧版本不需要读新语音文件。失败重试只落盘，不能重做录音、朗读、API或App操作。

权限/系统资源不写作用户授权偏好：每次主动录音从系统真实状态读取；不会把文件中的enabled当TCC已允许。ad-hoc构建更新后不承诺系统沿用旧权限，权限提示按实际安装版本确认。首选设备使用系统默认，不保存设备姓名、标识或音频。识别预览及语音令牌只在内存，不加入提示词或档案，插入草稿并主动发送后才按原文字规则处理。日志不记录音频、识别文字、聊天/记忆、人设、密钥或原始服务载荷；错误本地分类说明。

源码建议新增核心语音偏好/有界存储、Mac录音识别/朗读适配器、共享语音控制器及两个界面共用的语音控件；ChatController只加有界接入点，不散落多个权限服务。具体类型名、文件拆分、文案和布局细节由实施者决定，合同中的请求数、确认、数据流、恢复及兼容边界不得改变。新源码/测试显式登记Xcode并覆盖App与未托管Mac测试target。

## 7. 验证与交付

自动验证使用假权限/录音/识别/合成器、假凭据和网络、临时settingsURL及AI目录；不读取个人AI正文/正式Keychain、不自动录真实麦克风、发Apple或DeepSeek请求、试听个人App或修改登录项。必要的实际设备体验在安装后的App内由用户主动发起，未完成就记未测。
