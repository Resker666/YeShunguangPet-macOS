# 本地语音独立安装设计

日期：2026-10-28（Asia/Shanghai）。基线 `1d8f4f8`，现有日用版 0.6.0/build29。

状态：用户要求开始本地语音独立安装，选择“选择本地引擎包，在 App 内离线安装”，并于2026-10-28明确“认可书面设计，进入实施计划”。0.7.0/build30的本设计已获准，九项实施计划另待审核；当前只做只读调查和文档，不代表已实现或已通过搬移验证。沿用本会话原地实施、不另建工作树、最后一次独立整体代码评审的既有方式。没有本版推送、标签、Release 或模型上传授权。

## 1. 目标与边界

让 Apple Silicon Mac 用户在获得 App、独立引擎包和角色音色包后，不安装 Xcode、Homebrew、外部 Python，也不输入终端命令，就能在 App 中完成本地语音准备。安装后不依赖下载文件夹、原开发目录、原实验环境或联网服务。原 0.6.0 胡桃 e1 包及其他符合现有合同的角色包继续复用同一公共引擎。

成功标准：原生语音页选择本地包、查看基本信息并确认，后台校验/复制/自检，完成后使用新引擎；取消、磁盘不足、坏包、自检失败和保存失败都有可恢复结果。已配置用户不自动迁移，旧引擎在新引擎成功启用前保持可用。普通 App 仍能在未安装引擎时使用文字聊天和系统语音。

首版面向 arm64、macOS 14+，与 App 最低系统目标一致；实际测试设备仍只有当前 M4。Intel App 保持现状，禁用 ARM 引擎安装并显示原因，不提供 Rosetta/Intel 本地引擎。跨系统兼容目标与本机实测分别报告。

不做 App 内下载、下载服务器、引擎自动升级、公开模型发布、训练界面、多语言扩展、GPU/MPS 优化、流式语音或改变现有声音效果。不自动启用语音、绑定角色、朗读私人内容或注册登录项。

## 2. 方案与调查依据

| 方案 | 取舍与决定 |
| --- | --- |
| 用户取得独立引擎包，在 App 中离线安装 | 用户已选择。无需本轮建设下载服务，便于本地试装与故障恢复；包需单独获取，角色音色仍另行导入。 |
| App 下载并安装 | 获取步骤更少，但增加大文件托管、来源认证、断点/取消、更新与公开分发流程；本轮不采用。 |

作者提出以独立 DMG 携带引擎文件夹和安装说明：用户先在 Finder 打开 DMG，再在 App 中选择其内的引擎文件夹。App 不直接解析压缩包、挂载磁盘或执行包内安装脚本；从已挂载卷或普通文件夹复制都走同一流程。包安装后可弹出 DMG、删除原下载文件。

现有 `tools/prepare-local-voice.py` 从实验素材创建最终路径 venv 并运行 pip，App 不调用它。只读调查确认当前 venv 解释器指向 Homebrew；解释器及 `_jieba_fast_functions_py3` 的 Mach-O 声明最低系统为 27.0。已有 venv 的 315 个原生文件检查不能取代新运行时搬移验证；不能原样复制 venv，也不能只调低 Mach-O 声明冒充兼容。

运行时采用固定版本的 Python Build Standalone arm64 Python 3.12 分发，再由开发侧准备固定推理依赖和公共资源。该项目提供可安装到任意路径的独立 Python；这不是 PyTorch 及整个语音引擎已可搬移的证明。依据：[官方说明](https://github.com/astral-sh/python-build-standalone/blob/main/README.md)、[分发与许可说明](https://github.com/astral-sh/python-build-standalone/blob/main/docs/running.rst)。具体补丁版本、发行构建及其可信官方 SHA-256 由实施者在构建前固定到仓库小体积清单。

## 3. 可搬移引擎的构建与包合同

开发侧新增明确运行的打包工具；可下载已固定的官方 Python 和推理依赖，复制已核对的公共底模与固定上游源码。不把依赖安装步骤交给使用者，不调用个人日用环境，不改变原实验或备份。优先沿用现有 106 个依赖版本；对本机编译或不兼容的扩展使用 macOS 14 目标重建/兼容 wheel。需要改变依赖版本时记录理由、版本、来源和摘要，须真实生成及回归通过，不凭修改版本号或 load command 判断可用。

输出为 `dist/引擎包/<name>/` 及独立 DMG、SHA-256，全部忽略于 Git。文件夹固定含 `engine.json` 与 `payload/`；payload 固定含 `runtime/`、`source/`、`engine-assets.json` 和 `licenses/`。其中解释器路径固定为 `runtime/bin/python3.12`，上游源码固定提交 `b4570b876f5c086819ba84e3215472733c6a7b70`，引擎 profile 仍为 `gpt-sovits-v2proplus-cpu1`。公共资产清单只保留运行所需记录，不携带 experimentPath、个人绝对路径或试验候选信息。角色 S2、参考音频、训练录音、聊天、Keychain、缓存、测试输出和旧 venv 均不属于引擎包。

`engine.json` schema1 严格记录：包 ID/版本/显示名、架构 arm64、最低 macOS 14.0、Python 完整版本、profile、上游提交，以及 payload 中每份文件的相对路径、字节数、SHA-256、是否需要执行权限。路径不是任意可执行入口；App 只调用上述固定解释器和随 App 提供的固定自检/worker。清单不接受命令、URL、额外环境变量或安装脚本钩子。

作者提出边界：清单最多 16 MiB、100,000 个文件、路径深度 32、单文件最多 2 GiB、总文件内容最多 12 GiB；名称/版本有界且拒绝控制字符，严格 JSON 拒绝重复键、未知字段和版本。构建时以实际清单计算所需空间，不把压缩包大小当安装大小。若真实合规产物超过这些上限，先报告范围变化再调整，不能静默放宽。

包仅包含普通文件/目录。打包侧将确实位于 runtime 内的符号链接解析成独立普通文件，拒绝外部链接；清除无需运行的旧路径脚本和生成缓存，但保留所需模块/数据及第三方许可。App 拒绝根或内部符号链接、特殊文件、绝对/越界/重复及大小写或 Unicode 规范化冲突路径、未列入清单的内容（可忽略不复制 Finder 的 `.DS_Store`），按字节校验并后台流式复制，不加载大文件到内存。

打包侧审计所有 Mach-O 的架构、真实加载依赖、RPATH 和最低系统；不依赖 Homebrew、开发机用户目录或构建目录。区分 dylib ID 与真实 LC_LOAD，避免把无效 ID 文本误判为必需依赖。需修复的原生库重建/正确重链接后重新签名；对最终产物做摘要、许可库存和搬移运行验证。运行时无外部 Python/FFmpeg 可执行依赖，复用已预制 PCM 参考文件和现有中文推理路径。

## 4. 安装事务与兼容数据

运行目录继续相对于实际 settings 文件父目录的 `LocalVoice/Engine`，不硬编码个人路径。新增独立安装服务，与角色包索引事务分开；不改变主 schema13、角色 v2、语音偏好 schema1、角色包 schema1、语音库 schema1 或钥匙串标识。

现有 `current.json` schema1 的 `venv/bin/python` 仍可读取和使用。新描述采用 schema2，只指向本服务创建的 `Versions/<UUID>/runtime/bin/python3.12`，保存包身份和必要固定合同。App 不在启动时扫描或自动迁移旧引擎。卸载旧 App 版本不代表能识别 schema2；旧描述另作原字节备份，安装说明给出恢复边界。

流程为：选择文件夹 → 后台预检清单/平台/基本空间 → 显示包名、版本、占用及“安装后会运行本地引擎代码” → 用户确认 → 确认停止语音输出 → 取得既有 `use.lock` 排他锁 → 复制到新的 UUID 最终目录并逐文件复核 → 原生执行固定自检 → 原子切换描述。确认页明确仅选择可信来源，摘要用于完整性、不证明来源；预检不执行候选代码，确认后不执行包内 shell、pip 或安装钩子。固定自检由 App 提供，检查 Python、主要推理 import、源码/公共资源和离线环境，不使用角色包、麦克风、DeepSeek、私人聊天，也不自动发声。

预览仅持有有界清单和选取位置，不复制整包；确认时重新读取并核对同一清单，源变化失败。按文件描述符检查普通类型、边界并复制，目标只在私有新目录中创建；复制后的完整清单再次核对，源目录不被更改。新目录起初即为最终 UUID 路径，便于自检；仅 descriptor 切换赋予其当前引擎身份。

自检使用独立原生子进程，后台持续排空有界输出，限制 120 秒，取消时沿用准确自有 PID 的 TERM/等待/KILL/确认退出，不阻塞主线程。系统阻止启动、缺库、超时或验证失败均保留旧描述和旧引擎，不作假成功；显示可操作的失败原因，不自动清除 quarantine 或绕过系统检查。安装权限/签名和 Gatekeeper 的真实行为须单独记录。

空间预检按新包总量加余量，旧引擎不删除；复制期间的实际磁盘不足仍需可恢复处理。全程只有一项安装，排他锁失败即提示稍后重试，禁止与旧开发准备工具/worker 并发切换。复制文件的权限由 App 限定，除所需可执行文件外不接受外部任意 mode；不使用 shell 拼接包路径。

原子描述保存失败时不启用候选，保留已经确认且自检通过的新目录和可重试的切换意图；重试只做必要本地复核和保存，不重新下载、pip 或自动朗读。等待用户重试时释放锁，旧引擎可继续使用；重试先停输出、重新取得锁并核对原描述身份，其他进程已改变描述时拒绝覆盖并提示重新选择安装。安装大文件工作不占用聊天 FIFO，描述切换由唯一安装服务串行完成，退出协调器同时等待两类资源。取消/失败未启用目录仅清理本次 UUID；清理失败有独立待清理状态和重试入口，不能批量删除历史版本。旧引擎保留，不增加自动垃圾回收；修复就是从明确选择的引擎包重新安装新 UUID。强退/断电产生的未启用目录不在本轮自动扫描删除，文档说明会占空间。

## 5. 原生界面与生命周期

完整聊天窗的语音页新增“安装或修复本地引擎…”、“检查当前引擎”以及状态/阶段/进度/取消/重试。当前引擎版本、待安装包与当前角色音色分别显示，避免把安装引擎误解成绑定音色。文件面板选择引擎文件夹；确认前可取消；长任务显示累计字节或文件进度，无进度的自检只显示阶段，不虚构百分比。最小 440×420 窗仍可滚动到全部操作，轻窗不增加安装界面。

安装活动共享于两个聊天窗；启用后阻止新录音、朗读和角色语音包变更，文字聊天/桌宠动画不被大文件处理阻塞。入口拒绝睡眠/退出/阻挡模态等不合适状态。关闭语音页/完整窗会取消尚未确认的预览；已经确认的安装可在后台继续，菜单重开能看见同一任务，切换 full/quick 不重复创建任务。用户明确取消会停止复制/自检并清理本次资源，不切换引擎。

系统睡眠在可取消阶段请求停止，唤醒后显示取消结果，不自动续装或补播；descriptor 原子提交点前检查取消，提交成功后如实显示已安装，不能因迟到的取消反写旧描述。退出拒收新工作，取消未提交安装/等待清理及固定子进程；已进入原子提交的短事务先完成。未保存的切换/清理失败纳入既有退出错误和“重试/取消退出/明确继续退出”流程。已确认的候选在关窗、换角色或重试时不丢失；退出重试只处理本地持久化，不发声。

检查当前引擎同样后台、单飞、先停输出并持锁，检查实际描述/文件/依赖，不改绑定或启用偏好。检查失败不自动改用其他版本；原有本地输出失败时的一次系统音色回退仍按 0.6.0 规则执行。

## 6. 验证、交付与主要风险

自动测试使用隔离 settings/小型合成文件/假进程，不把大模型放入测试或普通 CI。覆盖严格包清单与路径/链接、数量/大小/摘要、源变化、磁盘/复制/切换失败、取消提交竞争、两种描述兼容、锁冲突、旧引擎保持、同一安装单飞、关窗/睡眠/退出/重试及准确 PID 清理。原窗口/语音/角色包、FIFO 和旧资料回归继续运行。

完整本地原生/Python/离线发版/双架构 App 分发回归后，一次新的独立整体代码评审并修复阻断问题。普通 App 的 CI 只验证小夹具和构建 App，不创建或上传大型引擎包；新增开发侧引擎打包脚本与小清单进入 Git，实际 Python/公共模型/DMG 仍只本地交付。

真实 M4 隔离验证必须包括：用新运行时从新文件夹安装；实际 PATH 仅系统目录、不带外部 Python 环境；删除或移开用于构建该新运行时的输入后，在中文/空格的新 settings 路径重开，导入独立 e1 包，生成新的中文句子并启动/停止播放；弹出源 DMG 后仍可重开使用。记录冷启动、生成耗时、峰值内存、停止/取消耗时和残留 PID。审计实际 Mach-O 依赖及解释器根路径，不能仅凭 PATH 证明无 Homebrew 依赖。不移动或删除原始实验、备份、旧日用引擎来制造隔离条件。

隔离环境中实际中断复制/自检、坏包/旧引擎修复、描述失败恢复均要有证据。macOS 14、其他 M 系列、不同内存设备及外机 Gatekeeper 首开若没有设备就列为待验证，不能把本机搬移或加载命令声明当外机通过。当前用户没有第二台 M 系列；既有 Intel 黑苹果不能用于 ARM 引擎实测。

本地交付包括新 App、独立 ARM 引擎 DMG/摘要、沿用的 e1 角色包和简明安装/修复说明。日用 App 更新前准确正常退出、盲备份旧 App/主设置/完整 AI 与当前引擎描述；不读取私人 AI 正文或正式 Keychain，不自动升级个人引擎。用户主动从新界面安装/试听验收；自动探针与可闻/物理操作分开报告。

主要风险为原生扩展的最低系统和外部库依赖、数 GiB 包的复制/空间/取消、Python 搬移后缓存或绝对路径、未公证代码的系统检查，以及安装与朗读/退出竞态。固定完整运行时、最终产物审计、隔离搬移实测、版本化安装/排他锁/原子切换和共享生命周期分别应对这些问题。若可搬移运行时本身不能真实运行，停止在隔离构建步骤报告阻碍，不以需要使用者手工安装 Python 的包充当成功交付。

0.7.0/build30、DMG 携带文件夹、Python Build Standalone、具体上限/超时、schema2 与保留旧版本最初均为作者提出的实现选择，现随本设计获准。类名、文件拆分、测试夹具、进度节流和最终兼容 wheel 的具体构建命令由实施者决定，需留下精确可复现的版本/摘要证据。本文已由一位新的只读可实施性检查者检查，结论为“nothing important left”；作者另补清公共清单不含实验路径、等待重试释放锁及描述变更保护。这是设计检查，不是实现或最终代码评审。用户随后认可本稿并要求进入实施计划，计划见`../plans/2026-10-28-macos-portable-voice-engine.md`；当前等待计划审核，不把设计批准当作产品已经实现。
