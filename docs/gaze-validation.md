# 鼠标注视验证

日期：2026-10-20，Mac mini M4 / macOS 27.0 / Xcode 27.0；版本0.1.6（build 7）。

## 已批准范围与实现

用户批准本会话实施鼠标注视：复用旧皮肤16个方向，待机靠近短暂注视后恢复，开关默认开启并保存，点击/拖动与手动动作优先，隐藏/睡眠/退出停止检测。沿用现有独立Mac仓库，在codex/macos-mouse-gaze本地分支实施，没有增加工作树。

参考只读Windows提交242aab0的MainWindow/TryShowLookAtCursor与PetBehaviorController，采用约100ms采样、距窗口中心42–520逻辑点的有效范围。坐标使用AppKit全局逻辑点，y轴向上；方向0/4/8/12分别上/右/下/左。当前缩放和位置决定中心，不按原图像素或backing scale计算。每次有效范围接近最多约2秒，鼠标离开有效范围后重新触发；菜单、设置和用户输入打断可重置本次接近。

使用公共NSEvent.mouseLocation，不使用事件钩子、不申请录屏/辅助功能。MouseGaze只做方向和短时状态；PetSession将采样、动画与点击期限交给同一个定时器。迟到时只采一次，不补采；同一方向不重新绘制。注视暂停idle播放时钟，结束后保留未完成帧的剩余时间；手动动作独立优先。没有新增随机动作、台词或游走。

菜单/设置打开、按下/待判定点击、拖动及手动动作时停止注视；隐藏、睡眠、退出时取消采样期限。关闭开关或皮肤缺少16帧时不读取鼠标。注视不改变角色窗口的非激活属性。配置升级到schema4，读取旧1–3版并默认开启；v4要求有效布尔字段，原有坏配置保护、选择皮肤和偏好保留。
