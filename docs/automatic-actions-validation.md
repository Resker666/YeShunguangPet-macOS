# 自动小动作验证

日期：2026-10-20，版本0.1.7（build 8），Mac mini M4 / macOS 27.0 / Xcode 27.0。

## 范围和行为

用户批准本会话实施低频自动动作。沿用独立Mac仓库，在codex/macos-automatic-actions本地分支开发，不另建工作树；推送和发布等待新指令。

设置新增“空闲时自动做动作”和15–120秒间隔，默认关闭、默认60秒，每次等待乘以0.75–1.25随机因子。关闭设置窗口后开始等待；菜单、设置、按下/待判定点击、拖动、手动动作、隐藏及睡眠冻结全局剩余等待。恢复最多触发一个动作，不追补历史次数。关闭功能中止当前自动动作，但不取消手动动作。

沿用Windows只读提交242aab0的behavior规则：条件any/cursorNear/cursorFar、相对权重、从选中时起的独立冷却。全局间隔与冷却都满足才可选；全部冷却时等最早期限。位置条件未满足时500ms重查，迟到只检查一次。cursorNear按鼠标到当前缩放窗口矩形最近距离≤80逻辑点（原版默认半径）；不使用注视的中心距离。仅到期需要位置条件时调用NSEvent.mouseLocation，不采集或记录鼠标坐标。

behavior省略/null时，只选择皮肤实际提供的挥手/跳跃，要求非循环且≤30秒；显式空规则不产生动作。三套现有角色behavior均为null，因此使用该兼容回退。支持自定义规则执行，不提供规则编辑器。规则相同且同一副本重载保留冷却，其他副本/默认角色或规则改变重置；退出不保存冷却。规则冷却在暂停期间继续流逝，全局等待冻结。

自动动作可替换短时注视；点击/拖动等中止自动动作，手动动作优先，单次完成回idle。动画、点击、注视与自动动作共用原有FrameScheduler，无新增轮询定时器。配置保存为schema5，读取1–4并默认自动动作关闭；v4的注视、缩放、置顶、导入UUID和位置保留，坏配置仍保护原字节。

## 原生回归

实现前96项通过。新增规则策略先建最小接口，随后出现预期断言失败；配置迁移与窗口接线分别出现7处和19处失败，完成实现后通过。首次窗口裁帧断言使用设备RGB颜色转换，受颜色空间转换影响得到0.581而非原字节128/255；改为直接检查裁帧像素字节128，保持对正确列的校验。另补“全局间隔已过、暂停期间冷却到期”回归，先观察nil而非waving的失败，再将全局等待期限与冷却观察期限分离。

最终全套原生114项（63 Core + 51 Mac）通过，日志.build/automatic-validation/native-final.log。新增覆盖随机间隔、权重边界、可用动作回退、空规则、冷却与位置条件重试、矩形半径、暂停剩余等待、停用重启等待、注视协调、真实裁帧字节、交互/手动优先、模拟生命周期、同副本冷却保留/换肤重置、保存失败重试及旧配置迁移。

独立只读评审发现1项Important：同目录、behavior仍为null的副本改变动画后，旧回退候选可能继续生效。现改为比较策略产生的有效规则，规则真正相同才保留冷却。回归覆盖删除动作、改成合法但超过30秒的动画、新增动作，修复前出现3处预期断言失败（reload-fallback-red-runtime.log），修复后全套114项通过。该夹具首次把waving设成loop，已被原严格解码拒绝，不算有效行为RED；改用合法清单复现后才修复。评审无Critical、无独立Minor、无Declined to judge，也没有拒绝修复项。评审记录review.md。
