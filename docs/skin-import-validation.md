# 皮肤导入与切换验证

日期：2026-10-20，Mac mini M4 / macOS 27.0 / Xcode 27.0。版本0.1.4（build 5）。

## 已批准范围与实现

沿用当前独立Mac仓库，在本地分支codex/macos-skin-switching上扩展已有加载、设置与窗口流程，不新增工作树。设置窗口选择解压后的皮肤文件夹或pet.json，使用原有严格校验，展示名称与待机首帧；确认后复制JSON和所声明PNG的原字节，再保存选择并切换。预览和导入使用同一份已校验快照，不受随后修改源文件影响，也不复制无关文件。

素材在配置同级Skins目录中以独立UUID保存。相同manifest ID的多次导入保留独立副本；本版没有历史列表或删除管理。文件复制先在临时目录完成，完整验证后移动到正式目录；失败清理本次临时副本。持久化选择成功后才更换当前图片和动画；保存失败时保留当前角色及原配置，并清理未使用的新副本。关闭窗口、取消预览、退出后的迟到任务不能触发切换。

配置schemaVersion 3兼容1/2。重开从App自己的素材副本恢复，素材缺失/损坏时使用默认角色并显示提示；JSON损坏/未知版本的文件仍受保护，需明确备份重置。--skin保持本次启动优先，其选择不会取代已记住的导入皮肤；“恢复默认皮肤”使用随附叶瞬光。

切换复用已有透明NSPanel，保留缩放、置顶与显示/隐藏状态，按新尺寸限制位置；停止旧调度、取消输入，使用新角色idle启动。隐藏或睡眠时保持暂停。
