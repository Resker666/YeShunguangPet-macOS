## 实现与使用

菜单栏爪印和角色右键的「聊天…」共用一个普通 AppKit 窗口：

- 「连接」页开启 AI，选择 DeepSeek 官方模型并保存密钥。密钥只在 App 内填写，保存到 macOS 钥匙串，不回显；连接偏好与密钥分别反馈结果。默认关闭，启动、开窗、保存设置不调用 API。
- 「人设」页编辑背景、性格、口吻和示例；应用成功才生效。离页、关窗或换角色丢弃未应用编辑。
- Enter 换行，⌘Enter 发送。组合输入未提交时，按钮和快捷键都拒绝发送。可停止、复制回复和清空本机记录。
- 按 manifest.id 保留最近12轮完整对话，重开可续聊；相同ID的导入副本共用。独立 AI/connection.json 与 AI/characters/<SHA256>.json 放在主配置旁。
- 停止或失败不把半条回答加入历史；完整回答保存失败可只重试本地，也可明确丢弃。关窗、换肤、睡眠与退出取消网络，已接受的文件事务仍按 FIFO 保存到原角色；退出汇总所有角色待存结果。
- 聊天可见时独立暂停注视、自动动作、走动和普通互动台词；最小化或隐藏后释放该来源。桌宠隐藏、安静或专注不取消主动聊天。成功保存后的挥手/短气泡遵守现有门控，不抢焦点。
