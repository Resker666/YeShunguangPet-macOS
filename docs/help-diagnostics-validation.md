## 发现与处理

- 新入口和诊断先以失败断言复现，再实现。隐私测试最初通过旧有保护不允许的偏好修改注入台词，未触发预期写入失败；改为先保存含个人台词的初始配置，再切换允许修改的偏好，确认原始错误确已发生，随后验证摘要没有泄露且不重试写盘。
- 首轮完整回归仅有旧测试固定“六个标签”的断言失败；改为真正执行“专注设置…”菜单动作并核对目标页。其余原生回归通过；最终完整334项通过。
- 评审发现记住导入ID后以`--skin`覆盖本次角色会误报来源。新增真实库副本＋`restoringSkin:false`回归，先观察`imported != external`失败，再按当前目录与内置/库目录的实际关系分类；同一测试还核对切换导入及恢复默认后的结果。另修正“缺失动作直接待机”的帮助措辞为按可用动作回退。
- 同系统对照仅移除新增帮助标签：六标签在520点宽可见，七标签在520点整体进入`>>`；560/600点七项均进入导航条。因此默认宽度调整为600、最小560，高度下限仍480。最终在560×458内容区执行七项原生控件action并核对每次绑定页，帮助可滚至末尾。探针最初以控件不支持的`accessibilityPerformPress`查找失败；定位后使用控件实际提供的action，不改产品交互，也不记作物理鼠标通过。
- 原生窗口缓存仍有历史选中标签黑胶囊现象，不能从缓存断言现场文字可读或不可读；保留系统样式，用户实际显示待验收。帮助正文和反馈文字在缓存中可读。
- 八附件校验首次误把含App目录的整个dist传给只允许八文件的工具，被拒绝；改为独立八文件目录后通过。不是产物校验缺陷，首次日志保留。
