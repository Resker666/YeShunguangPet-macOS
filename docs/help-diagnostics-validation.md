# 0.1.20 使用帮助与诊断复制验证记录

日期：2026-10-22（Asia/Shanghai）。用户已批准A+B，本会话在独立Mac仓库原地开发。当前为实施前记录，不表示已构建、测试或交付。仅授权本地开发；0.1.20推送、标签及Release未获授权。公开最新版为0.1.19。

## 已批准范围

- 复用SettingsWindowController增加“使用帮助”页，菜单栏与关于页提供常驻手动入口，不强制首启向导。
- 帮助覆盖显示/隐藏/召回、拖动与单双击、设置和换肤、专注计时、常见排查。
- 用户点击“复制诊断信息”才生成并复制文本：版本/build、macOS与运行架构、屏幕/窗口矩形、配置状态。
- 默认排除个人路径、个人台词、完整配置与原始错误，不上传，不新增schema、定时器或网络行为。
