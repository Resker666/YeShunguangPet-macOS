## 功能和探针边界

新增独立 `AI/voice.json`：schema1，8KiB上限、严格字段与重复键检查、无效文件保护及单文件备份重置；缺失读取不创建文件。偏好走原 ChatWriteQueue，立即禁用保持到新的明确启用保存成功；旧回执、保存失败、本地重试或重置不复活语音。正常退出继续等待已接受的原 FIFO 写入，失败只重试本地。

主动录音先确认朗读停止，再逐项检查权限，优先本机 zh-CN。45秒录音与5秒收尾由单次截止调度，空闲不加轮询；最终识别或手动接受预览只对完整角色、草稿修订和冻结选区做原子插入，仍需手动发送。联网提示只允许本次新录音，不发送旧 partial、不保留授权或自动重试。App不保存录音或合成文件。

一个语音控制器服务完整/轻聊天。正常交接先显示可用目标再隐藏原窗，合并中间可见性；全局阻挡或 marked input 拒绝时保留原窗。0.4.0 已知设置 sheet 内部切轻窗问题已补直接回归。真实 AppKit setMarkedText 和程序化控件动作通过，不等于物理输入法/焦点或真正最小化体验通过。

首次成功保存的普通回复才自动朗读，最多600 UTF-16完整字素并优先句尾；失败后的本地重试、工具提议/回执和记忆提炼零自动朗读。手动读最新已存 assistant 最多8000单元。音色缺失回退显示实际中文音色，不覆盖保存的ID；仅已安装 Apple 中文音色，无 Personal Voice 授权或第三方提供者请求。每次替换输出或开始录音前等待同一停止确认，最多1秒，不声称物理扬声器缓冲或环境回声消除。

隔离优化探针对每套真实素材验证：录音预览不发/不改草稿、最终选区插入及双窗交接、单次假模型后先落盘再朗读、长回复上限、旧语音回调、45+5秒超时、联网确认只开启新段、本地保存失败重试不增加模型/假钥匙串/音频、取消后晚授权、真实 marked text 门控、立即禁用失败重试不复活。主执行者查看浅深色最小窗口缓存PNG，并验证在线确认与语音设置按钮可滚动到达；缓存绘制不是物理桌面截图。

生产事件整合菜单、sheet、页面与窗口可见性、安静、睡眠和退出，不以失去key或隐藏桌宠单独取消。Focus 新 `allowsCompletionAudio` 只用于实际播放分支；原 `canPlayCompletionSound` 的命令门控保留。录音/收尾期间完成仍累计一次/计划分钟，取消录音后不补响，正常下一段可响，测试通过；这是替身播放计数，不是实际扬声器验收。
