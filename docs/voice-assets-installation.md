# 本地语音资源1.0.0安装说明

需要YeShunguangPet **0.7.0/build30或后续兼容版**、M系列Mac。资源包包含公共引擎和胡桃试用e1；App需从项目提供的兼容入口另行取得。旧公开0.1.19不支持本地角色语音。

## 1. 安装公共引擎

1. 先安装并打开兼容App。
2. 在Finder双击`YeShunguangPet-VoiceEngine-1.0.0-macOS-arm64.dmg`。
3. 从桌宠菜单打开完整「聊天…」，进入「语音」页，点击「安装或修复本地引擎…」。
4. 在文件面板左侧打开挂载的「角色语音引擎1.0.0」，选择里面的「本地中文引擎-1.0.0-arm64」文件夹，它应直接包含`engine.json`和`payload`。不要选存放DMG的下载目录或整个卷。
5. 点击「预览引擎」，核对1.0.0和约3.01GB展开体积，再点击「确认安装引擎」。等待复制/校验/自检成功后弹出DMG。

下载DMG约2.05GB，安装会占用约3.01GB并需要额外临时空间，旧引擎会保留。取消或失败不会启用坏包。可重新选择有效引擎执行修复，无需安装Xcode、Homebrew或外部Python，不需要终端命令。

## 2. 导入胡桃音色

1. 双击`YeShunguangPet-Voice-hutao-pilot-e1.zip`解压。
2. 得到「胡桃-试用-e1」文件夹和外层`来源与许可.md`。角色文件夹内应仅有`voice.json`、`s2.pth`、`reference.wav`，来源说明保留在外层。
3. 在App语音页导入该三文件目录。App当前不直接导入ZIP。
4. 为当前角色选择「胡桃 · 试用e1」，应用绑定并主动启用语音，再点击试听或朗读最近回复。导入和绑定不会自动发声。

首次启动需等待；连续生成会复用已加载引擎，空闲3分钟后释放。启动、生成和播放都可以停止；播放前失败可能提示并回退系统音色，正常取消不重读。安装后不依赖原下载目录，可弹出DMG并删除下载副本。

## 文件与适用范围

两份`.sha256`对应同名DMG/ZIP；`voice-assets.json`记录附件大小、摘要、来源和App兼容版本，升级App与更新引擎/角色包分别管理。避免把原2.31GB本地DMG的旧摘要用于这份2.05GB分发DMG。

当前真实设备仅M4，macOS14+是兼容目标；其他M系列、macOS14实机、外机Gatekeeper首开仍待测试。Intel App可用文字/系统语音，不安装此ARM引擎。App和引擎ad-hoc签名、未公证；遇到系统阻止时核对来源并按系统提示处理，安装不会自动清除安全隔离标记。

第三方模型、代码和胡桃原声采用各自来源说明。胡桃ZIP外层的`来源与许可.md`以及引擎`payload/licenses`记录已确认与未核实项；本项目MIT源码许可不能替代它们。
