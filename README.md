1. M 系列打开 `YeShunguangPet-0.1.19-macOS-arm64.dmg`；Intel测试机选择 `YeShunguangPet-0.1.19-macOS-x86_64.dmg`。将 App 拖到旁边的 Applications。
2. 弹出 DMG，从“应用程序”打开 App；菜单栏爪印提供操作和退出入口。

备用ZIP含对应架构的App和安装说明；安装、更新、卸载及配置保留说明见 [安装说明](docs/installation.txt)。0.1.1分发记录见 [分发记录](docs/distribution-validation.md)；双架构构建证据和限制见 [Intel测试包记录](docs/intel-validation.md)。

## 0.4.0 轻聊天与确认操作

菜单栏和角色右键提供「快速聊天…」与「完整聊天…」。轻窗跟随角色，约360×300，最小320×240，可调整大小、失焦保留；隐藏桌宠后仍可用。最近一轮及本轮用原生纯文字分句显示；两窗共享草稿、光标、请求和候选，展开/交接不断流。真正关闭会停止未接受请求并丢弃未确认卡片/记忆编辑，已接受写入照常完成。Enter换行、⌘Enter发送；输入法组合中禁止提交、交接及Esc关闭。

自然语言每轮最多提议一项：开始明确的1–120分钟专注（先保存为常用时长，休息时长不变，仅准备专注时可用）、暂停或继续当前专注、设置手动安静目标。操作卡始终先显示「尚未执行」，确认时复核真实状态；状态改走又改回也不会恢复旧卡。继续不能开始休息，关闭手动安静不会解除专注安静。

发送会增加4个工具定义和本App专注/安静运行资料，增加输入tokens。确认/取消不再请求API或钥匙串，结果由App生成「App操作回执」并保存为一轮完整问答。执行后回执保存失败只重试本地，不重复操作；丢弃记录不会撤销已执行结果。历史和人设文字不能自动执行操作；不支持App以外的操作。主配置schema13、角色档案v2、人设/12轮/记忆保持。

## 角色聊天与长期记忆

从菜单栏爪印或角色右键打开「聊天…」，在独立窗口的「连接」页开启 AI、选择 DeepSeek 模型并保存 API 密钥。密钥只在 App 中填写并保存到钥匙串，不写入配置或日志；启动和保存设置不会自动请求模型。

「人设」页可编辑角色背景、性格、口吻及示例。按角色ID保留最近12轮完整问答，重开可续聊。Enter换行，⌘Enter发送；可停止、复制和清空本机记录，完整回复保存失败时可只重试本地保存。真实 DeepSeek 对话往返与本机聊天整体体验已获用户确认；中文输入法、停止/重开及钥匙串提示等专项验证范围见[记录](docs/deepseek-chat-validation.md)。

「记忆」页点击「提炼记忆」会额外请求 DeepSeek，只使用当前角色已保存的最近12轮问答和已有记忆；不会自动定时提炼。每次最多5条候选，可展开用户原话来源、编辑并勾选，点击「保存所选」才成为长期记忆。未确认候选关闭窗口或换肤即丢弃，候选不会进入普通聊天上下文。

每个角色最多20条、每条最多200个UTF-16单元；后续普通聊天会携带已保存记忆，重开保留，同ID皮肤副本共用。可编辑、删除或清除记忆，满额时由你整理；清空聊天历史保留记忆，清除记忆保留历史。删除独立记忆不会移除人设/最近对话里的同文，也不删除服务商已收到的数据。记忆保存失败时原内容继续有效，可只重试本地；已确认但失败的变更跨关窗、换肤保留，正常退出会提示处理。

旧v1聊天档案读取时保留原字节，明确保存后写为包含记忆的v2；旧版App无法读取v2，会保护原文件。AI关闭或无网络仍可管理已有本地记忆，提炼需有效连接。密钥继续只在钥匙串中使用；本版真实提炼、确认和重开体验仍待用户在App验证。

## 打开与退出

本机构建产物为 `dist/YeShunguangPet.app`。双击 App，或在仓库根目录运行：

```bash
open dist/YeShunguangPet.app
```

菜单栏爪印提供 **显示/隐藏角色、召回角色、安静模式、锁定位置、设置、使用帮助、复制诊断信息、检查更新、退出**。拖动角色移动位置；单击挥手，双击跳跃。单击等待系统双击间隔后触发，拖动不会补发点击。缺失动作按原版规则回退。

右键角色可打开设置、切换安静模式或锁定位置、隐藏，以及手动挥手/跳跃。打开菜单取消待判定点击或正在进行的拖动，并暂停被动行为和快捷键；隐藏后可从菜单栏显示或召回。

菜单栏和角色右键的“切换皮肤”子菜单可直接选择默认角色或已导入的皮肤，当前项带勾选；相同显示名附短标识，损坏项置灰并说明原因。“管理皮肤…”打开设置中的皮肤页，继续提供导入、预览和删除。列表在后台刷新并缓存，读取失败可重试；导入/删除、模态确认或退出期间不能切换。换肤失败保留原角色，在菜单中提供原因及查看设置的入口。换肤保留当前隐藏、临时安静状态和原有偏好，所选皮肤按原流程保存，原素材不变。0.1.14引入时使用schema9，当前配置为schema13。证据与限制见[快捷换肤验证](docs/quick-skin-validation.md)。

通用页新增“拖动后贴边”和“锁定位置”，默认均关闭并自动保存。正常拖动松手距当前屏幕可用边缘12个逻辑点以内会贴齐，角落可同时贴齐两个方向；超出可用区域仍按原规则移回屏内。中断拖动、召回、缩放和屏幕修正不触发贴边。锁定暂停拖动和自动走动，保留单双击、召回、缩放及屏幕修正；解除后按原间隔等待走动。右键或菜单栏也可解除锁定。验证证据及限制见[记录](docs/context-placement-validation.md)。

设置现分为“皮肤、通用、互动、专注、快捷键、关于、帮助”七组，首次普通打开默认皮肤，重开保留本次运行选中的分组；帮助入口直接转到帮助页。任意组都可拖入支持的皮肤文件，自动转到皮肤页预览，仍需确认才导入。大小、置顶和登录启动在通用页，注视、台词及自动行为在互动页。

“快捷键”页可为显示/隐藏、召回、切换安静模式分别设置组合键，默认全部不绑定。勾选至少两个修饰键且包含Control或Option，选择美式物理键位对应的字母、数字或F1–F12，再点“应用”；“清除”解除该动作，“重试登记 / 释放”处理冲突或释放失败。切页或关窗丢弃未应用的编辑。系统拒绝或保存失败会保留原偏好，并明确显示已激活、未激活或仍待释放的状态。按住同一组合不会反复切换，菜单或模态确认打开时暂停，普通设置窗口打开时可用；不读取其他应用的键盘内容。

菜单“检查更新…”会打开关于页并发起一次匿名GitHub查询；关于页也可手动重试。启动、普通打开设置或唤醒不会自动查询。界面区分有新版、相同版本和开发版高于公开版；只有点击官方发布页或对应架构的DMG按钮才打开浏览器，不自动下载或安装。查询失败或无对应安装包会明确提示，不影响桌宠。查询不发送个人配置、皮肤、位置、快捷键或日志。

支持注视素材的皮肤在待机时会短暂看向附近鼠标，最多约2秒，然后恢复待机；鼠标离开有效范围再靠近可再次触发。“设置…”中的“注视鼠标”默认开启，可关闭并记住选择。关闭设置窗口后生效；菜单、设置、点击判定、拖动和手动动作期间暂停注视，隐藏、睡眠及退出时停止检测。不支持注视的皮肤继续正常待机，偏好保留。

“设置…”中的“空闲时自动做动作”默认关闭。开启后关闭设置窗口，角色会按约60秒的间隔做小动作；可调15–120秒，每次有±25%浮动。沿用皮肤behavior的条件、权重和冷却；旧皮肤从可用挥手/跳跃选择，显式空规则不触发。菜单、设置、点击、拖动、手动动作、隐藏及睡眠暂停全局等待，恢复后继续；关闭开关中止自动动作。

“设置…”中的“空闲时走动一小段”默认关闭，间隔20–180秒，默认约75秒且有±25%浮动。角色在当前屏幕可用区域内左右移动约60–120逻辑点，完成后回待机并保存位置。鼠标靠近时原地停下，离开后继续；点击、拖动、菜单、设置、手动动作、隐藏及睡眠会结束本次走动，再等待下一次。皮肤需同时提供左右循环行走动画；空间不足时保持待机。

菜单栏“安静模式”临时暂停注视、自动动作、走动及台词，保留待机动画和手动点击/拖动；不改原有开关，取消后继续等待，重开默认恢复正常。

“设置…”中的“显示互动台词”默认关闭。开启后，单击确认或拖动结束时显示约6秒的气泡，至少间隔30秒；优先使用皮肤台词，未提供时使用原版默认文案，显式空台词保持安静。双击只播放动作。气泡不抢焦点、不接收鼠标，菜单、设置、安静模式、隐藏、睡眠及换肤会收起。

0.1.15可在互动页展开“自定义当前角色台词”，编辑点击、拖动、专注完成和休息完成四类文案，每行一句，空白框表示该类不说话。点“应用台词”保存；切换角色、离开互动页或关闭设置会丢弃未应用编辑。个人台词优先于皮肤文案，按清单ID保存，相同ID副本共用；“恢复皮肤台词…”或已保存条目的“清除…”经确认后移除个人覆盖，不改素材文件。每类最多8句，每句80个UTF-16单元，最多16个角色、总8192个UTF-16单元；超过容量会提示且不生效，配置仍有64KiB上限。

“专注”页及菜单栏/角色右键的“专注计时”提供默认25/5分钟的专注和休息，分别可设1–120和1–60整数分钟，应用后保存。每段完成后由用户手动开始下一段，支持暂停、继续和重置，重置后才能改时长。专注运行时暂时暂停注视、自动动作、走动及互动台词，暂停或完成后恢复；用户手动安静开关原样保留。手动拖动/点击、换肤和锁定仍可使用。

0.1.16增加独立桌面计时小窗，默认显示并置顶。拖动顶部移动，点击图钉切换置顶；位置和显示偏好会记住。隐藏角色与关闭设置不会关闭计时窗；关闭小窗只隐藏，计时继续。菜单栏或角色右键的“专注计时”提供“显示桌面计时器”和“召回计时器”。窗口偏好写入失败会提示，可临时使用并重试保存；重开可能恢复旧偏好。验证与限制见[桌面计时记录](docs/desktop-focus-validation.md)。

0.1.17支持用小窗顶部的收缩/展开按钮，或“专注计时 → 紧凑计时窗”切换200×112紧凑模式；保留状态、倒计时和主要操作，重置可从菜单使用。模式和位置一起保存，切换时保持左上角并限制在屏幕内。完成后静态高亮至下一段或重置。“设置 → 专注 → 每段完成时播放提示音”默认关闭，开启后每段最多响一次；手动安静、睡眠、模态或退出阻挡时不响，也不补响。隐藏角色或计时窗不影响已开启的声音提醒。紧凑窗数字变橙表示窗口偏好未保存，可从专注计时菜单重试。配置schema12保留旧偏好，详见[本版验证记录](docs/focus-reminder-compact-validation.md)。

0.1.18在专注设置页及菜单栏/角色右键的“专注计时 → 快捷开始”提供15/25/45/60分钟。仅准备状态可选，先保存为常用专注时长再开始，休息时长不变；保存失败保留原时长并提示。运行、暂停或完成状态需先重置才可选预设，旧菜单命令不会意外重开一段。

“今日专注”在设置页及专注菜单显示完成次数与累计计划分钟。只累计完整完成的专注段，暂停不额外增加分钟，未完成段的重置/退出及休息不计；已完成汇总重开保留。睡眠沿用现有倒计时规则，包含在该段计划时长中；按结算时的本地日期归属，睡眠到期在唤醒结算当天计入。只保存一天汇总，日期变化显示新一天，不提供历史或实际清醒时长统计。保存失败保留本次待存汇总、提示并可重试；普通设置保存或正常退出也会带上待存统计，不按秒写盘。详见[本版记录](docs/focus-presets-statistics-validation.md)。

隐藏角色、关闭设置和打开菜单不暂停计时；睡眠时间计入，唤醒后最多结算一次。结束时若角色可见、已醒、未手动安静且没有菜单/设置/鼠标操作等阻挡，专注完成挥手、休息完成跳跃；开启台词时附对应气泡，完成台词可越过普通点击冷却。被阻挡时只保留计时小窗/菜单/专注页的完成状态，不自动显示角色或补播。退出结束当前段，重开保留时长、台词和已保存的当天统计；完成提示音可选、默认关闭，无系统通知。来源与真实验证边界见[记录](docs/focus-speech-validation.md)。

“设置…”中的“登录时启动”由macOS管理，不会默认替你开启。先将App安装到系统或用户的“应用程序”目录并从那里运行，再按需开启；系统要求允许时，设置会明确提示并提供登录项设置入口。状态来自系统，关闭失败不会假装已关闭；此开关不写入桌宠JSON配置。

App 不显示 Dock 图标；请从菜单栏退出。首次启动会在主屏右下角显示角色，后续恢复位置、大小和置顶偏好。关闭设置窗口不会退出桌宠。基础桌宠不需要录屏、辅助功能或麦克风权限。

支持目标为 macOS 14+ / arm64，x86_64仍为实验包；本机日用构建和验证环境为 Mac mini M4、macOS 27.0、Xcode 27.0。macOS 26.6.2 / Xcode 26.6云端自动检查见[CI记录](docs/ci.md#首次云端验证记录)，本台Sonoma14.8.9黑苹果的用户实机反馈见[兼容记录](docs/sonoma-compatibility-validation.md)。角色窗口采用非激活 NSPanel，默认浮动置顶；设置窗口可以正常获得键盘焦点。Spaces、全屏、Stage Manager 和真实睡眠恢复的当前证据见 [验证记录](docs/validation.md)，不能保证覆盖所有系统窗口。

## 皮肤与配置

默认随附未经改写的叶瞬光 JSON/PNG。角色默认以格尺寸对应逻辑点显示，叶瞬光为192×208点。“设置…”提供50%–200%大小调整及置顶开关，立即生效并自动保存；关闭置顶后角色可能被其他窗口遮挡，可从菜单栏召回。

在设置的“皮肤”区域点“选择皮肤…”，选择包含一套皮肤的ZIP（0.1.10新增）、皮肤文件夹或`pet.json`，查看名称与待机首帧预览，再点“导入并使用”。清单与对应PNG会按原字节复制到`~/Library/Application Support/YeShunguangPet-macOS/Skins/`，不依赖下载目录中的原文件；再次启动恢复所选皮肤。校验、复制或保存失败时继续使用当前角色，显示具体原因。“恢复默认皮肤”切回随附叶瞬光。取消预览不会导入；关闭设置窗口会取消尚未确认的操作。

0.1.11也可将单个ZIP、皮肤文件夹或`pet.json`从Finder拖到设置窗口，窗口高亮后松开，仍先预览、再确认。一次只接受一个本地文件或文件夹；处理期间、文件面板/确认对话框打开时不接收新拖入。拖动角色本身仍用于移动桌宠。

设置中的“已导入皮肤”自动识别之前保存的副本，显示名称、待机缩略图与使用状态；点“使用”即可切换，不必重新选择原文件，也不增加副本。可以确认删除未使用的副本，原始文件保持不变；当前使用、配置仍记住的皮肤或原配置受保护时不可删除。损坏的副本单独显示错误，可以删除，不影响其他皮肤。“刷新皮肤列表”重新读取受管理目录。

重复导入仍会保存独立副本；只想换回旧角色时请使用列表。正常退出会等待当前导入完成，再清理本次未使用的副本；强制结束或断电没有此保证，也不会自动清空历史副本。

ZIP可直接在根目录放`pet.json`和PNG，也可套常见外层文件夹（最多16层路径）。一次只导入一套；含多套皮肤时请先解压再选其中一套。支持普通Stored/Deflate ZIP及UTF-8/Unicode路径记录；加密、分卷、ZIP64、其他压缩方式或旧式非UTF-8文件名请先解压。包内最多512个条目，ZIP不超过80 MiB、单文件不超过64 MiB、声明展开总量不超过128 MiB，JSON仍限制128 KiB。拒绝路径越界、链接、重复/冲突路径、大小与CRC不符。预览只临时还原所需JSON/PNG并清理，不将包内任意路径写入磁盘。

也可以从终端指定一个仅用于本次启动的本地皮肤：

```bash
dist/YeShunguangPet.app/Contents/MacOS/YeShunguangPet --skin /绝对路径/pet.json
```

显式指定的皮肤加载失败时，菜单栏显示错误并保留退出入口，不静默回退。皮肤文件不会被编辑。`lookDirections`用于16向注视；`behavior`用于可选自动动作；`speech.click`、`speech.drag`、`speech.focusCompleted`和`speech.breakCompleted`分别用于点击、拖动及两种计时完成台词，个人覆盖优先，显示仍受台词开关与互动条件控制。详见 [兼容矩阵](docs/skin-compatibility.md)。输入按角色矩形处理，逐像素透明区域穿透未验证。

位置、贴边/锁定、显示偏好、注视/自动动作/走动/台词开关、对应间隔、已应用快捷键、计时时长、个人台词、计时窗偏好、所选导入皮肤和一天专注汇总保存在 `~/Library/Application Support/YeShunguangPet-macOS/settings.json`。新版读取schemaVersion 1–12，保存为13；迁移保留已有字段，新增零值专注汇总。更早版本按原规则补齐缺少的偏好。旧版App无法读取新版配置，会保留原文件而不覆盖。导入素材缺失或损坏时恢复默认角色，在菜单栏和设置中提示原因。角色隐藏状态不跨进程保存，重新启动默认显示；计时窗的显示偏好会保存。损坏或未知版本配置不会被自动覆盖；菜单栏提供“备份原配置并重置”。保存失败会在设置窗口和菜单栏提示，可重试，也可明确选择继续退出。

开发检查可设置 `YSGPET_SETTINGS_PATH` 为隔离配置的绝对路径，导入素材也隔离在该文件同级的`Skins/`；`YSGPET_METRICS_PATH` 为退出时的本地运行指标输出路径。普通启动不启用指标输出，不联网、不上传日志。

## 构建和测试

需要完整 Xcode，使用系统框架，无第三方运行库或工程生成依赖。

```bash
bash scripts/test.sh
bash scripts/build-app.sh
python3 scripts/smoke-app.py
bash scripts/package-app.sh
# 额外构建并打包Intel实验版（不会替换上述ARM App）：
bash scripts/build-app.sh x86_64
bash scripts/package-app.sh x86_64
# 两个架构的App均构建后，在M系列开发机执行完整分发检查：
python3 -m unittest discover -s Tests/Distribution -v
# 指定已搬离工程目录的 App，并验证二次启动恢复位置：
python3 scripts/smoke-app.py --app /绝对路径/YeShunguangPet.app --check-restore
```

也可在 Xcode 打开 `YeShunguangPet.xcodeproj`，选择共享 scheme `YeShunguangPet`。测试使用临时目录，不修改个人配置。`.build/` 和 `dist/` 不进入 Git。

构建需要 Xcode；使用 App 不需要。默认ARM App在`dist/YeShunguangPet.app`，Intel App在`dist/x86_64/YeShunguangPet.app`。两者主程序和嵌入框架架构必须一致；打包核对所选架构、Info.plist声明和两个Mach-O的实际macOS 14.0最低版本，拒绝错误标签、混合框架或最低版本不符的包。

打包输出均在dist根目录，带版本号和架构的DMG、ZIP及各自SHA-256文件。例如在 dist/ 内运行 `shasum -a 256 -c YeShunguangPet-0.4.0-macOS-arm64.dmg.sha256`。SHA-256用于文件完整性校验，不等同于开发者认证。包仍未做Developer ID签名或公证，`Contents/Resources/build-info.json`记录构建提交和架构。0.1.19已公开发布八份附件，标签及云端包来源为`37a73f0cd163dbb172300d0df269a4b7575180b5`，两路CI通过并获本台黑苹果整体体验通过反馈；本地历史交付包来源仍为`5164ba9`。0.1.20从干净来源`e15b739`本地交付，后续已普通同步`a90c5e1`且两路CI通过。0.1.21本地App/八附件来自干净`76f9c615563b42359041f12ea38999ba516dfd6e`，已安装运行；用户已授权普通同步和云端核验，未授权标签或Release。

App 图标由原仓库 ICO 转换，原图256×256；大尺寸仅作缩放，不新增绘制细节。需要重新生成时运行 `bash tools/make-icon.sh`，使用系统 sips/iconutil，无外部图像工具依赖。

### 系统中文语音（0.5.0）

在完整聊天的「语音」页启用，点击「应用语音设置」保存后生效；默认关闭。两种聊天窗共用录音与朗读，打开页面或启用本身不会发声、录音或请求权限。「立即关闭语音」会立即停止，本次保持关闭；保存失败可只重试本地。

准备好系统声音输入设备，在首次主动录音时允许麦克风与语音识别权限。点击「开始说话」，每段最多45秒；点击「结束识别」后最多等5秒。预览尚未发送，最终文字填入录音开始时的草稿选区，由你检查、编辑并手动发送。失败预览可手动接受；重新录音会丢弃旧预览。换角色、改草稿、关闭聊天或阻挡模态出现后，旧识别结果不能覆盖当前草稿。

优先在本机识别中文；设备或语言不支持时可选择「允许本次在线识别」开始一段新录音，录音可能交给 Apple 处理。此选择不保存、不自动重试。App不保存录音，DeepSeek仅接收你手动发送的文字及原有聊天上下文。

系统已安装的 Apple 中文音色可在语音页选择；如无音色，请在系统设置的辅助功能／朗读内容中下载。试听使用已应用的音色和语速；所选音色缺失时显示实际中文回退音色，不覆盖原选择。普通回复完整生成且首次成功保存后可自动朗读，长回复最多朗读开头600个 UTF-16 单元；手动朗读最近已存回复最多8000个单元，不增加API请求。操作卡、记忆提炼、失败及本地保存重试均不自动朗读。

安静模式、聊天隐藏或最小化、离开对话页、菜单和阻挡模态会停止朗读且不补读；语音页可以主动试听。录音前先确认朗读停止，录音及等待识别期间只抑制App自身的专注完成提示音，计时与统计照常结算。只隐藏桌宠仍可使用可见聊天窗，轻／完整窗交接保留同一段语音活动。识别和中文音色可用性取决于本机设备及系统；Intel与实际录音、可闻朗读须实机验证。
